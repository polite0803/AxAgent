AxAgent 设计规范

基于 Modern Minimal 方向（Linear / Vercel 风格）的色彩、字体与组件规范。

版本 1.0 — 适用于桌面端 Tauri 应用。浅色/深色双模式支持。

1. 色彩系统

使用 OKLch 色彩空间以确保跨模式感知均匀性。所有颜色通过 CSS 自定义属性暴露。

中性色板

oklch(20% 0.008 250)
--fg (dark)
oklch(92% 0.005 250)
--muted (dark)
oklch(55% 0.008 250)
--border (dark)
oklch(26% 0.008 250)
--bg (light)
oklch(99% 0.002 240)
--surface (light)
oklch(100% 0 0)
--fg (light)
oklch(18% 0.012 250)

强调色与语义色

--accent (dark)
oklch(65% 0.18 255)
--accent (light)
oklch(58% 0.18 255)
--green (success)
oklch(62% 0.18 145)
--red (error)
oklch(60% 0.20 28)
--amber (warning)
oklch(65% 0.18 85)

使用规则

  • 强调色（--accent）用于：选中态、按钮、链接、激活指示器。每屏不超过 2 处。
  • 语义色仅用于状态指示：成功/绿色、错误/红色、警告/琥珀色。
  • 禁用态用 --border + --muted 表示，降低不透明度至 40%。
  • 背景色（--bg）为应用最底层；表面色（--surface）用于卡片、侧栏、面板。
  • 边框（--border）为发丝级 1px solid，无阴影代替边框来表达层级。
  • 强调色背景变体（--accent-soft / --accent-bg）通过降低不透明度产生。

尺寸: sm(24px) / default(30px) / lg(36px)。圆角 6px（--radius）。图标按钮 = 宽=高。

5.2 输入框 (Input)

状态样式
Defaultbg: --surface, border: --border, 圆角 6px
Focusborder: --accent, box-shadow: 0 0 0 2px --accent-soft
Disabledopacity: .4, pointer-events: none
Placeholdercolor: --muted, opacity: .5

高度 30px，水平内边距 10px。文本输入框无阴影，只有 1px 边框。

5.3 标签 (Tab)

Tab 栏高度 34px，标签项高度 26px。激活态使用 --accent-soft 背景 + --accent 文字。

每项最大宽度 180px，超长截断加省略号。关闭按钮仅在 hover 时显示。

新标签按钮在栏末尾，26×26px 图标按钮。

5.4 导航项 (Nav Item)

36×36px 图标按钮。激活态使用 --accent-soft 背景 + 左侧 3px 指示线（--accent）。

悬浮: --accent-bg 背景。分隔线 24px 宽、1px 高。

5.5 徽章 (Badge)

变体样式
Accentbg: --accent-bg, fg: --accent
Greenbg: --green-bg, fg: --green
Redbg: --red-bg, fg: --red
Amberbg: --amber-bg, fg: --amber
Neutralbg: --accent-bg, fg: --muted

高度 20px，圆角 4px，字号 11px。仅用于状态标签和计数。

5.6 卡片 (Card)

bg: --surface, border: 1px solid --border, 圆角 10px（--radius-lg）。无阴影。

可悬浮卡片 hover 时 bg: --accent-bg。信息类卡片（统计数字）用大号等宽字体。

5.7 表格 (Table)

表头: 11.5px / 大写字母间距 / --surface 背景。表体: 12.5px / tabular-nums。

行悬浮 hover: td 背景变 --accent-bg。边框: 1px solid --border，6px 圆角包裹。

5.8 对话框 (Dialog/Modal)

覆盖层: rgba(0,0,0,.4)。对话框: bg --surface, 24px 内边距, 420px 宽, 10px 圆角。

阴影: 0 8px 32px rgba(0,0,0,.15)。入场动画: slideUp 200ms。

5.9 下拉菜单 (Dropdown)

最小宽度 180px, 4px 内边距, 6px 圆角。菜单项 6px 上下内边距 + 10px 左右内边距, 4px 圆角。

快捷键在右侧，11px 等宽字体。分隔符 1px 高。危险项红色。

5.10 状态指示 (Status Dot)

6×6px 圆形点。online (--green), busy (--amber), offline (--border)。

用于 StatusBar 和右面板的 Agent 列表。

5.11 消息气泡 (Message)

28px 方形头像（用户/U 和助手/A 区分），12px 粗体文字，6px 圆角。

用户名 11.5px 粗体，正文 13.5px 行高 1.65。代码块: 12.5px / 6px 圆角 / --surface 背景。

消息工具按钮组在 hover 时显示（opacity 0→1），24×24px 图标按钮。

6. 暗色/亮色模式

通过 data-theme 属性切换。自定义属性自动适配两种模式。

:root {
  --bg:      oklch(99% 0.002 240);  /* light: near-white */
  --surface: oklch(100% 0 0);
  --fg:      oklch(18% 0.012 250);
  --muted:   oklch(54% 0.012 250);
  --border:  oklch(92% 0.005 250);
  --accent:  oklch(58% 0.18 255);
}
[data-theme="dark"] {
  --bg:      oklch(16% 0.006 250);   /* dark: near-black with cool tint */
  --surface: oklch(20% 0.008 250);
  --fg:      oklch(92% 0.005 250);
  --muted:   oklch(55% 0.008 250);
  --border:  oklch(26% 0.008 250);
  --accent:  oklch(65% 0.18 255);    /* lighter in dark for contrast */
}

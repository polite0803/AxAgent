# AxAgent 全面功能缺陷审计报告

> **审计日期**: 2026-07-02\
> **当前版本**: 2.8.0 (Cargo workspace, 30 crates)\
> **审计范围**: 前端(React/TS, 754文件) + 后端(Rust/Tauri, 96命令模块, 30 crates) + 工作流引擎 + 构建/CI/配置\
> **审计方法**: 四路并行代理审计 + 去重合并\
> **覆盖文件数**: ~1200+

## 执行摘要

本次全链路审计发现 **78 个功能缺陷**，按严重程度分布：

| 严重程度    | 数量 | 关键影响                                       |
| ----------- | ---- | ---------------------------------------------- |
| 🔴 CRITICAL | 8    | 运行时 panic、CI 永远失败、数据静默丢失        |
| 🟠 HIGH     | 17   | 翻译缺失、类型安全绕过、工具实现空洞、重连缺失 |
| 🟡 MEDIUM   | 27   | 竞态条件、死锁风险、死代码、不正确配置         |
| 🟢 LOW      | 26   | 代码异味、文档过时、测试覆盖不足               |

**核心发现**: 项目存在三类系统性问题：

1. **类型安全侵蚀** — 工作流引擎中 47+ 处 `as unknown as` 强制转换 + Rhai 引擎 5 处不安全 `unwrap()` + 后端多处 `std::sync::RwLock` 绕过异步安全
2. **国际化债务** — 10 种语言各缺失 258 个翻译键，多个组件硬编码中文文本
3. **测试/CI 覆盖率漏洞** — CI 中的 `test-build.yml` 在 macOS 上永远失败（`apt-get` vs `brew`），集成测试未在 CI 执行，`tests/` 与 `src/` 双配置割裂

## 🔴 CRITICAL 级缺陷 (8)

### C-1. [生产] 工作流引擎 `audit_recorder` Mutex 中毒 → panic

- **文件**: `crates/rt-workflow/src/work_engine/engine/mod.rs:3024`
- **问题**: `self.audit_recorder.lock().unwrap()` — 若 Mutex 中毒直接 panic，无恢复逻辑
- **影响**: 一次 poisoned mutex（如上层 unwrap panic）会导致后续所有审计记录调用崩溃
- **修复**: 使用 `map_err` 处理 poisoned mutex，记录 error 日志后降级跳过

### C-2. [生产] `pause_signal` 不受保护的 `unwrap()`

- **文件**: `crates/rt-workflow/src/work_engine/engine/mod.rs:1763`
- **问题**: `state.pause_signal.clone().unwrap()` — 并发场景下可能变成 `None`
- **修复**: 改为 `unwrap_or_else(|| Arc::new(tokio::sync::Notify::new()))`

### C-3. [生产] Rhai 值转换 5 处不安全 `unwrap()`

- **文件**: `crates/rt-workflow/src/expression_engine/rhai_eval.rs:52-73`
- **问题**: `dynamic_to_value()` 先 `is::<T>()` 再 `as_int().unwrap()` 的反模式 — 高度耦合，重构易脱钩
- **修复**: 统一使用 Rhai 的 `try_cast::<T>()` API

### C-4. [前端] BalanceBadge 调用不存在于 providerStore 的方法

- **文件**: `src/components/settings/BalanceBadge.tsx:17`
- **问题**: `(s as any).fetchBalance` — 使用 `as any` 强制调用类型定义中不存在的方法，运行时必然报错
- **修复**: 在 providerStore 中添加 `fetchBalance` 方法或增加运行时 guard

### C-5. [CI] `test-build.yml` 在 macOS 上永远失败

- **文件**: `.github/workflows/test-build.yml:43`
- **问题**: macOS runner 上运行 `sudo apt-get install -y protobuf-compiler` — macOS 无 apt-get
- **修复**: 改为 `brew install protobuf`

### C-6. [CI] `pr-ci.yml` 集成测试不执行

- **文件**: `.github/workflows/pr-ci.yml`
- **问题**: `test-unit` 作业仅运行 `npm run test:run`（src/ 测试），`tests/` 目录的集成测试（vitest.config.ts）不在任何 CI 作业中
- **修复**: 添加 `test:integration` 执行步骤或将双配置合并

### C-7. [代码] `crates/billing/` 孤立 crate

- **文件**: `src-tauri/crates/billing/`
- **问题**: 目录存在但无 `Cargo.toml`，不在 `[workspace] members` 中。要么遗弃残留，要么迁移不完整
- **修复**: 删除或补全 Cargo.toml 并加入 workspace

### C-8. [前端] 10 种语言各缺 258 个 i18n 键

- **文件**: `src/i18n/locales/{ar,de,es,fr,hi,ja,ko,ru,zh-TW}.json`
- **问题**: en-US.json 含 7265 键，其他语言仅 ~7008-7011，zh-CN 也比 en-US 少 19 键
- **修复**: 建立 CI 强制检查所有 locale 键数一致，运行同步脚本

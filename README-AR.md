## ما هو AxAgent؟

**AxAgent v2.0** هو تطبيق AI متعدد المنصات متكامل لسطح المكتب/الجوال، يدمج قدرات وكلاء AI المتقدمة وأدوات تطوير غنية. يدعم مزودي نماذج متعددين، وتنفيذ خطوط الأنابيب المستقل، والتنسيق المرئي لسير العمل، وإدارة المعرفة المحلية، وبوابة API مدمجة، يغطي خمس منصات **Windows / macOS / Linux / Android / iOS**.

## الميزات الرئيسية

### 🤖 دعم نماذج AI

- **دعم متعدد المزودين** — تكامل أصلي مع OpenAI، Anthropic Claude، Google Gemini، Ollama، OpenClaw، Hermes وجميع واجهات API المتوافقة مع OpenAI
- **تدوير مفاتيح متعددة** — تكوين مفاتيح API متعددة لكل مزود مع تدوير تلقائي لتوزيع ضغط حدود المعدل
- **دعم النماذج المحلية** — دعم كامل لنماذج Ollama المحلية، بما في ذلك إدارة ملفات GGUF/GGML
- **محرك استدلال Candle** — استدلال Candle محلي مدمج، دعم واجهات rerank/judge، تنزيل GGUF عند الطلب
- **إدارة النماذج** — جلب قوائم النماذج البعيدة، تخصيص المعلمات (الحرارة، الحد الأقصى للرموز، top-p، إلخ)
- **إخراج البث** — عرض في الوقت الفعلي رمز برمز مع كتل تفكير قابلة للطي (Claude Extended Thinking)
- **مقارنة النماذج المتعددة** — سؤال نماذج متعددة في وقت واحد مع مقارنة جنباً إلى جنب
- **استدعاءات الدوال** — استدعاءات دوال منظمة لجميع المزودين المدعومين
- **OpenAI Responses API** — دعم نقل بصيغة OpenAI Responses
- **Realtime API** — دفع أحداث WebSocket متوافق مع OpenAI Realtime API
- **توليد صور AI** — DALL-E 3 و Flux (Replicate)، إعدادات أحجام متعددة (1:1/16:9/9:16/4:3)، مطالبات سلبية
- **التوجيه الذكي للنماذج** — توجيه تلقائي حسب نوع المهمة (مراجعة الكود/التلخيص/الترجمة)، قواعد توجيه مخصصة
- **المكالمة الصوتية** — محادثة صوتية في الوقت الفعلي عبر OpenAI Realtime API، تبديل حالات الاتصال/التحدث/الاستماع

### 🔐 نظام وكلاء AI

نظام الوكلاء مبني على بنية متطورة بالخصائص التالية:

- **محرك استدلال ReAct** — دمج الاستدلال والفعل، مع تحقق ذاتي مدمج لتنفيذ مهام موثوق
- **مخطط هرمي** — تفكيك المهام المعقدة إلى خطط منظمة بمراحل وتبعيات
- **مفكك المهام** — تفكيك تلقائي للمهام المعقدة إلى مهام فرعية قابلة للتنفيذ
- **بحث عميق** — تنسيق بحث متعدد المصادر، وتتبع الاقتباسات وتقييم الموثوقية
- **التحقق من الحقائق** — التحقق من الحقائق المدعوم بالذكاء الاصطناعي وتصنيف المصادر
- **تنسيق البحث** — تنسيق مزودي بحث متعددين، مع التخطيط وتوليف النتائج
- **البحث الأكاديمي** — البحث في الأدبيات الأكاديمية وتحليل الاقتباسات
- **التحكم في الكمبيوتر** — نقرات الماوس، وإدخال لوحة المفاتيح، والتمرير بالشاشة المتحكم بها بالذكاء الاصطناعي، مع تحليل النموذج البصري
- **إدراك الشاشة** — التقاط لقطات الشاشة وتحليلها بالنموذج البصري لتحديد عناصر واجهة المستخدم
- **ثلاثة مستويات من الأذونات** — افتراضي (يتطلب موافقة)، قبول التعديلات (موافقة تلقائية)، وصول كامل (بدون مطالبات)
- **عزل وضع الحماية** — عمليات الوكيل مقيدة بشكل صارم بدليل العمل المحدد
- **لوحة موافقة الأدوات** — عرض في الوقت الفعلي لطلبات استدعاء الأدوات مع موافقة فردية
- **تتبع التكاليف** — عرض في الوقت الفعلي لاستخدام الرموز وإحصائيات التكاليف لكل جلسة
- **إيقاف مؤقت/استئناف** — تعليق تنفيذ الوكيل في أي وقت واستئنافه لاحقاً
- **نظام نقاط التفتيش** — نقاط تفتيش مستمرة للاسترداد بعد الأعطال وإعادة اتصال الجلسات
- **محرك استرداد الأخطاء** — تصنيف تلقائي للأخطاء، وتحليل الأسباب الجذرية، وتنفيذ استراتيجيات الاسترداد
- **كشف الحلقات** — اكتشاف ومقاطعة تلقائية للسلوك الحلقي في استدلال الوكيل
- **سلسلة الأفكار** — تصور عملية اتخاذ القرار للوكيل، تفكيك خطوة بخطوة
- **الوضع الاستباقي** — يمكن للوكيل تقديم اقتراحات وتنفيذ إجراءات بشكل استباقي
- **إدارة الأهداف** — صيانة وتتبع أهداف التنفيذ وسياق الوكيل
- **لوحة تجمع الوكلاء** — تصور حالة الوكيل الفرعي/Worker/خطوة سير العمل في الوقت الفعلي
- **لوحة تأمل الوكيل** — تسجيل جودة ما بعد المهمة، تحليل الكفاءة، أنماط الأخطاء، اقتراحات التحسين
- **محدد الخبراء** — استيراد/تصدير/تخصيص أدوار الخبراء، تصفية الفئات، إعدادات مسبقة مدمجة
- **شجرة التسلسل الهرمي للوكلاء** — تصور التسلسل الهرمي للوكلاء وطوبولوجيا التعاون
- **مصنف النوايا** — تحديد تلقائي لنوع نية إدخال المستخدم
- **إدارة حالة المعتقدات** — الحفاظ على حالة فهم سياق الوكيل
- **مقيّم الأهداف** — تقييم إنجاز أهداف المهمة وجودتها
- **إدارة نافذة السياق** — إدارة ذكية لنافذة السياق، تحسين استخدام الرموز
- **ذاكرة المشروع** — استمرار المعرفة على مستوى المشروع عبر الجلسات
- **إدارة قاعدة المعرفة** — عمليات CRUD لقاعدة المعرفة
- **نظام الملاحظات** — تخزين واسترجاع منظم للملاحظات داخل الوكلاء

### 👥 تعاون الوكلاء المتعددين

- **تنسيق الوكلاء الفرعيين** — بنية رئيسي-تابع مع دعم وكلاء تعاونيين متعددين
- **التنفيذ المتوازي** — معالجة متوازية من وكلاء متعددين مع جدولة واعية بالتبعيات
- **المناظرة الخصومة** — جولات مناقشة مؤيد/معارض مع تسجيل نقاط قوة الحجج وتتبع الدحض
- **أدوار الوكلاء** — أدوار محددة مسبقاً (باحث، مخطط، مطور، مراجع، مُركّب) للعمل الجماعي
- **منسق الوكلاء** — توجيه مركزي للرسائل وإدارة الحالة لفرق الوكلاء المتعددين
- **رسم الاتصالات** — تصور التفاعلات وتدفقات الرسائل بين الوكلاء
- **مجموعة Swarm** — مجموعة وكلاء متعددة العمليات مع مزامنة الأذونات وإعادة الاتصال التلقائي
- **نظام Buddy** — وكلاء رفقاء قابلون للتكوين مع تعريف الأنواع والسمات
- **الذاكرة المشتركة** — مساحة ذاكرة مشتركة بين الوكلاء مع إحصائيات واستعلامات
- **Cron الفريق** — جدولة مهام cron على مستوى الفريق
- **لوحة التعاون** — إدارة جلسات التعاون في الوقت الفعلي، مشاركة رمز الدعوة، أدوار المشاركين (مالك/محرر/مشاهد)
- **مشاركة الجلسة** — رابط مشاركة بنقرة واحدة، تكوين أذونات الوصول للطرفية/الملفات/النموذج

### ⭐ نظام المهارات

- **سوق المهارات** — سوق مدمج لتصفح وتثبيت المهارات المساهمة من المجتمع
- **إنشاء المهارات** — إنشاء تلقائي للمهارات من المقترحات، مع محرر Markdown
- **تطور المهارات** — تحليل وتحسين تلقائي مدعوم بالذكاء الاصطناعي للمهارات الموجودة بناءً على ملاحظات التنفيذ
- **لوحة تطور المهارات** — تصور جيل التطور، أفضل/متوسط ملاءمة، حالة التقارب
- **مطابقة المهارات** — مطابقة دلالية، توصية بالمهارات ذات الصلة بسياق المحادثة
- **تفكيك المهارات** — تفكيك تلقائي للمهام المعقدة إلى مهارات ذرية قابلة للتنفيذ (مساعدة LLM/متعددة الجولات/تحقق سير العمل)
- **الأدوات المُنشأة** — إنشاء وتسجيل تلقائي مدعوم بالذكاء الاصطناعي لأدوات جديدة لتوسيع قدرات الوكيل
- **مركز المهارات** — واجهة مركزية لاكتشاف المهارات وإدارة التكوين
- **عميل مركز المهارات** — تكامل مع مركز مهارات بعيد مع مشاركة مجتمعية
- **التحقق من تبعيات المهارات** — اكتشاف تلقائي لتبعيات المهارات وتوافر الأدوات
- **حاوية وضع حماية المهارات** — تنفيذ آمن للمهارات في بيئة معزولة

### 🔄 نظام سير العمل

ينفذ محرك سير العمل نظام تنسيق مهام قائم على DAG:

- **محرر سير العمل المرئي** — مصمم سير العمل بالسحب والإفلات مع اتصال وتكوين العقد
- **أنواع عقد غنية** — 15 نوع عقدة: مشغل، وكيل، LLM، شرط، متوازي، حلقة، دمج، تأخير، أداة، كود، سير عمل فرعي، بحث متجه، تحليل مستند، تحقق، نهاية
- **قوالب سير العمل** — إعدادات مسبقة مدمجة: مراجعة الكود، إصلاح الأخطاء، التوثيق، الاختبار، إعادة البناء، الاستكشاف، الأداء، الأمان، تطوير الميزات
- **تنفيذ DAG** — فرز طوبولوجي بخوارزمية Kahn، مع كشف الدورات
- **الجدولة المتوازية** — تنفيذ خط أنابيب، الخطوات السريعة لا تنتظر البطيئة
- **استراتيجية إعادة المحاولة** — تراجع أسي، عدد أقصى قابل للتكوين لإعادة المحاولة لكل خطوة
- **الإكمال الجزئي** — الخطوات الفاشلة لا تحظر الخطوات اللاحقة المستقلة
- **إدارة الإصدارات** — التحكم في إصدارات قوالب سير العمل مع التراجع
- **سجل التنفيذ** — سجل مفصل مع تتبع الحالة والتصحيح
- **مساعدة AI** — تصميم سير العمل بمساعدة AI، توصية العقد وتحسين مطالبات الوكلاء
- **التحقق الدلالي** — تحقق دلالي من سير العمل، كشف المشاكل المحتملة
- **استيراد n8n** — دعم استيراد سير العمل من دليل n8n
- **لوحة التصحيح** — تصحيح في الوقت الفعلي وتصور الحالة أثناء تنفيذ سير العمل

### 📚 المعرفة والذاكرة

- **قاعدة المعرفة (RAG)** — دعم قواعد معرفة متعددة، رفع المستندات، تحليل تلقائي، تقسيم وفهرسة متجهة
- **البحث الهجين** — مزيج من بحث التشابه المتجه وتصنيف BM25 للنص الكامل
- **Self-RAG** — توليد معزز بالاسترجاع الذاتي، تحديد ذكي لضرورة الاسترجاع وملاءمة النتائج
- **إعادة الترتيب** — إعادة ترتيب بالترميز المتقاطع لتحسين دقة الاسترجاع
- **خط أنابيب الاستدعاء ثلاثي المستويات** — آلية استدعاء متعددة المستويات مع فهرس AST + بحث متجه + FTS5
- **رسم المعرفة** — تصور علاقات الكيان-المعرفة (الكيانات، السمات، العلاقات، التدفقات، الواجهات)
- **نظام Wiki** — مترجم ومحقق LLM Wiki، مع تصوير رسم المعرفة ومزامنة تزايدي
- **ملاحظات Wiki** — نظام ملاحظات بروابط ثنائية الاتجاه، عرض رسمي ومزامنة تلقائية للروابط
- **نظام الذاكرة** — ذاكرة متعددة مساحات الأسماء، مع إدخال يدوي أو استخراج تلقائي بالذكاء الاصطناعي
- **ذاكرة الحلقة المغلقة** — تكامل مزودي الذاكرة المستمرة Honcho و Mem0
- **بحث النص الكامل FTS5** — بحث سريع في المحادثات والملفات والذكريات
- **بحث الجلسات** — بحث متقدم في جميع جلسات المحادثة
- **إدارة السياق** — إرفاق مرن للملفات، نتائج البحث، مقاطع المعرفة، الذكريات، مخرجات الأدوات
- **محلل المستندات** — تحليل واستخراج تلقائي لمحتوى المستندات متعددة التنسيقات
- **الفهرسة التزايدي** — تحديث تزايدي للفهرس عند تغيير الملفات

### البناء من الكود المصدري

#### المتطلبات المسبقة

- [Node.js](https://nodejs.org/) 20+
- [Rust](https://www.rust-lang.org/) 1.75+
- [npm](https://www.npmjs.com/) 10+
- Windows: [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) + أهداف Rust MSVC

#### خطوات البناء

```bash
# استنساخ المستودع
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent

# تثبيت التبعيات
npm install

# وضع التطوير
npm run tauri dev

# بناء الواجهة الأمامية فقط
npm run build

# بناء تطبيق سطح المكتب
npm run tauri build
```

مخرجات البناء في `src-tauri/target/release/`.

### الاختبار

```bash
# اختبارات الوحدة
npm run test          # Vitest مراقب
npm run test:run      # Vitest تشغيل واحد

# اختبارات E2E
npm run test:e2e      # Playwright
npm run test:e2e:ui   # Playwright وضع واجهة المستخدم

# اختبارات خلفية Rust
cd src-tauri && cargo nextest run   # cargo-nextest (أسرع 2-3 مرات)
cd src-tauri && cargo test          # اختبارات قياسية

# التحقق من الأنواع
npm run typecheck     # TypeScript
cd src-tauri && cargo clippy -- -D warnings  # Rust

# تنسيق الكود
npm run format        # dprint
cd src-tauri && cargo fmt

# فحص CI
npm run ci:check
```

## الأسئلة الشائعة

### macOS: "التطبيق تالف" أو "لا يمكن التحقق من المطور"

بما أن التطبيق غير موقع من Apple:

**1. السماح بالتطبيقات من "أي مصدر"**
```bash
sudo spctl --master-disable
```

ثم اذهب إلى **إعدادات النظام → الخصوصية والأمان → الأمان** واختر **أي مصدر**.

**2. إزالة سمة العزل**
```bash
sudo xattr -dr com.apple.quarantine /Applications/AxAgent.app
```

**3. خطوة إضافية لـ macOS Ventura+**
اذهب إلى **إعدادات النظام → الخصوصية والأمان** وانقر على **فتح على أي حال**.

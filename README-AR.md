**AxAgent** هو عميل سطح مكتب مفتوح المصدر ومتعدد المنصات لمساعد الذكاء الاصطناعي، يدعم **Windows / macOS / Linux / Android / iOS**. إنه يتجاوز مجرد واجهة محادثة — فهو يدمج محرك وكيل ReAct، وتنسيق سير عمل بصري، وقواعد معرفة RAG محلية، وامتدادات بروتوكول MCP، وبوابة موحّدة متعددة النماذج، وأتمتة المتصفح، والتحكم بالحاسوب، ليكون محطة عمل ذكاء اصطناعي للتطوير اليومي والبحث وإدارة المعرفة والأتمتة.

## ما الذي يحله AxAgent

يعالج AxAgent ثلاث مشكلات رئيسية:

1. **تنسيق موحّد متعدد النماذج**: استخدم OpenAI وAnthropic Claude وGoogle Gemini ونماذج Ollama المحلية وأي واجهة برمجة تطبيقات متوافقة مع OpenAI في واجهة واحدة، مع تدوير مفاتيح متعددة وتوجيه ذكي للنماذج ومقارنة البث
2. **تشغيل قدرات الذكاء الاصطناعي**: توسيع الذكاء الاصطناعي من "المحادثة" إلى "التنفيذ" — من خلال أكثر من 47 أداة مدمجة، وسير عمل بصري، وامتدادات MCP، وأتمتة المتصفح، والتحكم بالحاسوب، مما يتيح للذكاء الاصطناعي معالجة الملفات وتشغيل الأكواد وإدارة Git وجدولة المهام مباشرة
3. **سيادة البيانات المحلية أولاً**: تُخزَّن محادثات الذكاء الاصطناعي وقواعد المعرفة والذكريات وملفات الإعداد جميعها في قاعدة بيانات SQLite محلية. وتُشفَّر مفاتيح API باستخدام AES-256-GCM. وتعمل الوظائف الأساسية دون أي خدمات سحابية لجهات خارجية.

## القدرات الأساسية

### محرك متعدد النماذج

- **9 محوّلات مزوّدين**: OpenAI (Chat Completions + Responses + Realtime)، وAnthropic Claude، وGoogle Gemini، وOllama (مع إدارة GGUF)، وOpenClaw، وHermes، وجميع واجهات API المتوافقة مع OpenAI
- **تدوير مفاتيح متعددة**: تهيئة عدة مفاتيح API لكل مزوّد مع تدوير تلقائي حسب الحصص لتجنب الانقطاع بسبب حدود المعدل
- **توجيه ذكي**: اختيار النموذج الأنسب تلقائيًا حسب نوع المهمة (مراجعة الكود / التلخيص / الترجمة / العام)، مع قواعد توجيه قابلة للتخصيص
- **مراقبة صحة المزوّدين**: تتبع فوري لمعدلات النجاح والكمون والتوفر لكل مزوّد، مع تراجع تلقائي متدرّج (ProviderTier)
- **توليد الصور بالذكاء الاصطناعي**: DALL-E 3 وFlux (Replicate) مع إعدادات مسبقة لأحجام متعددة
- **صوت فوري**: محادثة صوتية عبر WebSocket مبنية على OpenAI Realtime API، مع مقاطعة ونسخ فوري بالبث

### نظام الوكلاء

بُني نظام الوكلاء بالكامل على **محرك ReAct (Reasoning + Acting)**، ويشمل الأنظمة الفرعية المطبَّقة التالية:

- **المخطّط الهرمي** (`hierarchical_planner`): يقسّم المهام المعقدة إلى خطط منظَّمة Phase → Task مع علاقات تبعية، تُترجم إلى تنفيذ طوبولوجي DAG
- **البحث العميق** (`deep_research`): تنسيق بحث متعدد المصادر يشمل تخطيط البحث (`search_planner`)، وتنفيذ البحث (`search_orchestrator`)، وتوليف المحتوى (`content_synthesizer`)، وتتبّع الاقتباسات (`citation_tracker`)
- **مدقّق الحقائق** (`fact_checker`): تحقق مدعوم بالذكاء الاصطناعي من الحقائق مع مصنّف المصادر (`source_classifier`)، ومدقّق المصادر (`source_validator`)، ومُقيّم الموثوقية (`credibility_evaluator`)
- **شجرة الأفكار** (`tree_of_thoughts`): استكشاف استدلال عبر مسارات متعددة مع تقييم الفروع والتراجع
- **المُراجِع** (`reflector`): تقييم ذاتي واقتراحات تحسين بعد المهمة
- **المُتحقّق الذاتي** (`self_verifier`): تحقق تلقائي من نتائج الاستدلال مع كشف الدورات (`cycle_detector`) لمنع الحلقات اللانهائية
- **استرداد الأخطاء** (`error_recovery_engine`): تصنيف أنواع الأخطاء → اختيار استراتيجية الاسترداد → إعادة محاولة تلقائية أو تعديل الخطة، مع تراجع أسّي
- **اختبار A/B** (`ab_testing`): تقييم مقارن لاستراتيجيات استدلال مختلفة
- **نظام التقييم** (`evaluator`): إطار عمل معايير مدمج يدعم مجموعات البيانات والمقاييس وتوليد التقارير
- **ضبط LoRA الدقيق** (`fine_tune`): خط أنابيب تدريب مدمج مع إدارة محوّلات LoRA
- **مُحسِّن RL** (`rl_optimizer`): تعزيز التعلم القائم على السياسات من خلال تعليقات الخبرة مع إعادة تشغيل الخبرة وتدرّجات السياسة
- **مُوصي الأدوات** (`tool_recommender`): تحليل أنماط استخدام الأدوات واقتراحها بناءً على السياق

**تعاون متعدد الوكلاء**:

- بنية تنسيق رئيسي/تابع (`coordinator`) مع تنفيذ موازٍ للوكلاء الفرعيين وجدولة واعية بالتبعيات
- سبورة مشتركة (`shared_blackboard`) لتبادل المعلومات بين الوكلاء
- وضع نقاش تنافسي بجولات مؤيد/معارض وتسجيل قوة الحجج
- وضع عنقود سرب مع مجموعات وكلاء متعددة العمليات تدعم مزامنة الأذونات وإعادة الاتصال التلقائي
- الوضع الاستباقي (`proactive_mode`): يمكن للوكلاء اقتراح التوصيات والإجراءات بشكل استباقي

**التحكم بالحاسوب**: نقرات الماوس ومدخلات لوحة المفاتيح وتمرير الشاشة مدفوعة بالذكاء الاصطناعي مع ثلاثة مستويات أذونات (Default / Accept Edits / Full Access) وعزل مسارات في بيئة رملية

**أتمتة المتصفح**: التحكم بالمتصفح عبر بروتوكول CDP مع دعم التنقل ولقطات الشاشة والنقرات وملء النماذج واستخراج النص ومراقبة حالة الصفحة

### نظام المهارات (Skill System)

- **سوق المهارات**: تصفّح المهارات المجتمعية وتثبيتها
- **إنشاء بمساعدة الذكاء الاصطناعي**: إنشاء تلقائي لهياكل المهارات من مقترحات بلغة طبيعية
- **تطوّر المهارات** (`evolution_engine`): تحليل وتحسين المهارات تلقائيًا بناءً على تعليقات التنفيذ
- **المطابقة الدلالية** (`skill`): مطابقة دلالية وتوصية تلقائية بالمهارات ذات الصلة بناءً على سياق المحادثة
- **تفكيك المهارات** (`skill_decomposition`): تفكيك تلقائي للمهام المعقدة إلى مجموعات مهارات ذرية
- **أدوات مولّدة** (`generated_tool`): أدوات جديدة مولّدة ومسجّلة بالذكاء الاصطناعي
- **تنفيذ في بيئة رملية** (`sandbox`): تُنفَّذ المهارات بأمان في بيئات رملية معزولة

### سير العمل البصري

محرّر سير عمل DAG بالسحب والإفلات مبني على ReactFlow 12:

- **17 نوع عقدة**: Trigger، وAgent، وLLM Call، وConditional Branch، وParallel Fork، وLoop، وMerge، وDelay، وTool Call، وCode Execution، وSub-workflow، وVector Retrieval، وDocument Parsing، وValidation، وEnd، وBusiness Rule، وAgent Role
- **تنفيذ بفرز طوبولوجي Kahn**: كشف تلقائي للتبعيات الدورية مع جدولة خط أنابيب متوازٍ
- **قوالب مدمجة**: مراجعة الكود، وإصلاح الأخطاء، وتوليد المستندات، والاختبار، وإعادة البناء، والاستكشاف، وتحليل الأداء، وتدقيق الأمان، وتطوير الميزات
- **تسلسل YAML**: تدعم تعريفات سير العمل استيراد/تصدير YAML
- **إدارة الإصدارات**: التحكم في إصدارات قوالب سير العمل
- **مساعدة الذكاء الاصطناعي**: تصميم سير عمل بمساعدة الذكاء الاصطناعي وتوصيات العقد

### إدارة المعرفة

- **RAG متعدد قواعد المعرفة**: رفع المستندات → تحليل تلقائي (PDF/DOCX/XLSX/PPTX/TXT) → تقسيم → فهرسة متجهية
- **استرجاع هجين**: تشابه المتجهات (sqlite-vec + تضمينات candle المحلية) + بحث نصي كامل BM25 (FTS5) مع ترتيب هجين
- **Self-RAG**: توليد معزّز بالاسترجاع الذاتي مع تأمل وتحقق تلقائي من نتائج الاسترجاع
- **إعادة الترتيب**: إعادة ترتيب النتائج باستخدام cross-encoder لتحسين الدقة
- **رسم المعرفة**: استخراج الكيانات (`EntityExtractor`) → بناء العلاقات → رسم بياني مرئي
- **مراقبة الملفات**: مراقبة فورية لتغييرات الملفات عبر `notify` مع فهرسة تزايدية تلقائية
- **Wiki للنماذج اللغوية الكبيرة**: مُترجِم ومدقّق Wiki بمساعدة الذكاء الاصطناعي مع إضافة متصفح لقص الويكي

### نظام الذاكرة

- **ذاكرة متعددة النطاقات**: معزولة حسب المشروع/الموضوع، تدعم الإدخال اليدوي والاستخراج التلقائي بالذكاء الاصطناعي
- **تكامل الاستمرارية**: ذاكرة مغلقة الحلقة مع Honcho وMem0
- **ملف المستخدم** (`user_profile` / `profile`): تعلّم تلقائي لأسلوب الترميز (المسافات البادئة/التسمية/التعليقات)، وتفضيلات الحزمة التقنية، وأسلوب التواصل
- **نقل الأسلوب** (`style`): استخراج سمات أسلوب الكود → تطبيقها على الكود المولّد بالذكاء الاصطناعي
- **تكامل الحلم** (`dream`): دمج تلقائي في الخلفية لشظايا الذاكرة وأنماط السلوك في معرفة منظّمة
- **ذاكرة المشروع** (`project_memory`): استمرارية سياق لكل مشروع

### بوابة API

خادم بوابة HTTP + WebSocket مدمج مبني على `axum`:

- **نقاط نهاية متوافقة**: OpenAI `/v1/chat/completions`، وClaude Messages API، وGemini API، بالإضافة إلى OpenAI Responses وRealtime WebSocket
- **إدارة المفاتيح**: توليد المفاتيح وإلغاؤها وتمكينها/تعطيلها مع دعم الانتهاء
- **تتبّع الاستخدام**: عدّ الطلبات وإحصاءات استهلاك الرموز لكل مفتاح ومزوّد وتاريخ مع تصدير مقاييس Prometheus
- **الحد من المعدل**: خوارزمية حزمة الرموز (token bucket) عبر `governor` مع سياسات حد معدل قابلة للتهيئة
- **SSL/TLS**: شهادات موقّعة ذاتيًا مدمجة (`rcgen`) مع دعم للشهادات المخصصة
- **الربط الخارجي**: تكامل بنقرة واحدة مع Claude CLI وOpenCode وأدوات خارجية أخرى مع مزامنة تلقائية لمفاتيح API
- **تذاكر فورية**: تذاكر مصادقة مؤقتة مبنية على HMAC لتمرير اتصالات WebSocket الفورية بأمان

### تكامل منصات المراسلة

DingTalk، وFeishu، وQQ، وSlack، وWeChat، وWhatsApp، وTelegram، وDiscord

### بروتوكول MCP

تنفيذ كامل لـ MCP (بروتوكول سياق النموذج) مبني على crate `rmcp`:

- **طبقة النقل**: عملية فرعية stdio + Streamable HTTP + WebSocket
- **مصادقة OAuth**: دعم تدفق تفويض OAuth لخوادم MCP
- **اكتشاف الأدوات**: اكتشاف وتسجيل تلقائي للأدوات التي تكشفها خوادم MCP
- **مدير MCP**: إدارة دورة حياة الخادم، وفحوص الصحة، وإعادة الاتصال التلقائي

### نظام الإضافات

بنية إضافات ثلاثية المستويات متوافقة مع OpenClaw (مدمجة / مجمّعة / خارجية)، تدعم:

- تثبيت حزم npm مع واجهة سوق مدمجة للبحث والتثبيت
- تعريف بيان الإضافة، وإعلان الأذونات، والتنفيذ المعزول في بيئة رملية
- تسجيل أدوات مخصصة، ومزوّدي الوكلاء، واعتراض الخطافات
- مثبّت المهارات: تثبيت المهارات من حزم الإضافات في نظام المهارات

### الأمان

- **تشفير AES-256-GCM**: تخزين مشفّر محلي لمفاتيح API والإعدادات الحساسة (crate `crypto`)
- **حماية حقن الأوامر**: خط دفاعي رباعي المستويات (`prompt-guard`) — كشف الأنماط → تهريب الفواصل → غلاف XML → تسميات الثقة، متكامل في الجلسات وبناء الأوامر وGit وRAG عبر الخط بأكمله
- **حماية SSRF** (`ssrf_guard`): فحوص أمان عناوين URL التي تمنع الطلبات إلى عناوين الشبكة الداخلية
- **تصفية المحتوى** (`content_filter`): تصفية أمان للمحتوى متعدد الأنواع
- **الحد من المعدل** (`rate_limiter`): حد معدل بحزمة الرموز لاستدعاءات الأدوات وطلبات API
- **قاطع الدائرة** (`circuit_breaker`): فصل الدائرة تلقائيًا عند حالات الفشل المتتالية لحماية استقرار النظام
- **التحكم في الوصول** (`tool_access`): تحكم في أذونات الوصول للأدوات القائمة على السياسات
- **عزل البيئة الرملية**: عزل بيئة التنفيذ للوكلاء والمهارات

### تجربة المطوّر

- **التتبع الموزّع** (`telemetry`): تكامل OpenTelemetry مع تصور Span/Trace
- **القياس عن بُعد** (`telemetry`): تسجيل منظّم، ومقاييس وقت التشغيل، وجمع أحداث الأداء
- **تصحيح بالإعادة**: تسجيل مسار تنفيذ الوكيل (`trajectory_recorder`) وإعادته
- **لوحة DevTools**: عارض خط زمني Trace/Span مدمج في الواجهة الأمامية
- **إطار المعايير**: معايير Criterion (tool_exec / llm_call / search)، وتقييم SWE-bench وTerminal-bench

### تجربة سطح المكتب والجوال

- **تخطيط متجاوب**: نقاط توقف CSS متكيّفة مع سطح المكتب / الجهاز اللوحي / الجوال (600px / 900px)
- **11 لغة**: الصينية المبسّطة، والصينية التقليدية، والإنجليزية، واليابانية، والكورية، والفرنسية، والألمانية، والإسبانية، والروسية، والهندية، والعربية
- **محرك السمات** (`rt-theme`): سمة داكنة/فاتحة تتبع تفضيل النظام أو تبديل يدوي، مخصّصة بعمق مع Ant Design 6
- **محرّر Monaco**: محرّر أكواد مدمج مع تمييز بناء الجملة ومعاينة الفروق ودعم لغات متعددة
- **طرفيّة xterm.js**: محاكي طرفية مدمج يدعم WebLinks وUnicode 11 والبحث
- **D2 / Mermaid / ECharts**: مخططات معمارية، ومخططات انسيابية، ورسوم بيانية تفاعلية
- **مشاركة الجلسة**: توليد رابط مشاركة بنقرة واحدة مع أذونات وصول قابلة للتهيئة
- **علبة النظام + اختصارات عامة + تشغيل تلقائي**: تشغيل خلفي غير متطفل
- **تحديث تلقائي**: كشف تلقائي لتحديثات الإصدارات عبر GitHub Releases
- **دعم الوكيل**: تهيئة وكيل HTTP وSOCKS5

### بنية الواجهة الخلفية: نمط حقن التبعية Harness

تستخدم الواجهة الخلفية بنية Rust workspace مع **32 crate**، وتتبع **نمط البنية Harness**:

```
جميع crates منفصلة عبر واجهات سمة (trait) معرّفة في axagent-harness.
يقوم وقت التشغيل (axagent-runtime) بتجميع التبعيات وحقنها وقت التشغيل.

اتجاه التبعية: التطبيقات الملموسة → harness ← المستدعون
```

**harness** هو حجر الزاوية المعماري — صفر منطق أعمال، صفر تطبيقات ملموسة، يحتوي فقط على تعريفات السمات، وDTO بيانات نقية، وثوابت، وأنواع أخطاء موحّدة. تعتمد عليه جميع crates الأخرى ولا يعتمد على أي crate آخر من axagent-*.

```

├── harness/          # حجر الزاوية المعماري — واجهات السمات، وDTOs، وأنواع أخطاء موحّدة، وعقود DI
│                     #   أكثر من 200 تعريف سمة تغطي: Agent/Provider/Tool/RAG/Storage/
│                     #   MCP/Plugins/Security/Observability/Memory/Learning/Browser/Messaging

├── entities/         # نماذج كيانات SeaORM

├── credential/       # تخزين آمن للبيانات الاعتمادية (مفاتيح API وغيرها)
├── storage/          # تجريد تخزين الملفات (محلي / S3 / WebDAV)، ودعم قراءة/كتابة ZIP
```

### البناء

```bash
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent
npm install
npm run tauri dev      # وضع التطوير
npm run tauri build    # بناء الإنتاج
```

توجد عناصر البناء في `src-tauri/target/release/`.

### الاختبار

```bash
npm run test           # اختبارات وحدة الواجهة الأمامية (مراقبة Vitest)

npm run test:e2e       # اختبارات E2E (Playwright)

# اختبارات الواجهة الخلفية Rust
cd src-tauri && cargo nextest run
cd src-tauri && cargo test

# فحص الأنواع والفحص البرمجي
npm run typecheck
cd src-tauri && cargo clippy -- -D warnings
npm run format

npm run ci:check
```

# 风险管理 SKILL

## 核心原则

1. **本金安全第一**：任何单笔交易的潜在亏损 ≤ 总资金 2%
2. **分散但不稀释**：5-10 只股票覆盖 3-5 个行业
3. **止损铁律**：到达止损位无条件执行
4. **仓位动态调整**：根据市场强度加减仓

## 仓位控制

### 单票仓位上限

| 条件                     | 单票上限 |
| ------------------------ | -------- |
| 高确定性（多维度共振）   | 20%      |
| 中等确定性（双维度共振） | 15%      |
| 低确定性（单维度信号）   | 10%      |
| 试仓 / 观察              | 5%       |

### 总仓位控制

| 市场状态                              | 总仓位  |
| ------------------------------------- | ------- |
| 牛市（指数站上 60 日均线 + 量能放大） | 80-100% |
| 震荡市（指数在均线附近反复）          | 50-70%  |
| 熊市（指数跌破 60 日均线）            | 20-40%  |
| 暴跌风险（系统性事件）                | 0-20%   |

### 加仓规则

- **金字塔加仓**：首次 50%，回调后加 30%，突破后加 20%
- **亏损不加仓**：浮亏状态下禁止加仓（摊平成本是新手陷阱）
- **盈利加仓**：浮盈 ≥ 5% 后可加仓，加仓部分止损上移到成本价

## 止损策略

### 硬止损（必须执行）

- **百分比止损**：入场价 -5%（短线）/ -8%（中长线）
- **技术止损**：跌破关键支撑位（前低 / 均线 / 趋势线）
- **时间止损**：买入后 10 个交易日不涨，考虑退出

### 软止损（建议执行）

- **移动止损**：浮盈 ≥ 10% 后，止损上移到入场价 + 3%
- **回撤止损**：从最高点回撤 ≥ 8% 止盈
- **量价背离**：放量滞涨 / 缩量新高，警惕减仓

### 止盈策略

- **目标止盈**：达到目标价 1.0 倍止盈一半，1.2 倍止盈 30%，剩余 20% 移动止盈
- **趋势止盈**：跌破 10 日均线减半仓，跌破 20 日均线清仓
- **基本面止盈**：业绩透支 / 估值过高（PE > 行业 1.5 倍标准差）

## 分散投资

### 行业分散

- 单行业仓位 ≤ 40%
- 覆盖 3-5 个不相关行业（如：科技 + 消费 + 周期 + 医药）
- 避免同质化（如同时持有 5 只银行股不算分散）

### 风格分散

- 价值股 / 成长股 / 周期股 按 4:4:2 配置
- 大盘股 / 中盘股 / 小盘股 按 5:3:2 配置

### 时间分散

- 分批建仓（避免一次性满仓）
- 定投策略（适用于震荡市）
- 分批止盈（避免一次性清仓）

## 风险指标监控

### 个股层面

- 单日跌幅 > 5%：触发风险评估
- 5 日累计跌幅 > 10%：考虑减仓
- 距离止损位 < 2%：预警

### 组合层面

- 组合日回撤 > 3%：检查持仓相关性
- 组合周回撤 > 7%：降低总仓位
- 组合月回撤 > 12%：暂停开新仓

### 市场层面

- 大盘跌破 60 日均线：总仓位降至 50% 以下
- 大盘成交量连续 3 日萎缩：警惕流动性风险
- 北向资金连续 5 日净流出：外资撤离信号

## 心理纪律

- **不在亏损时加仓摊平**（最常见的新手错误）
- **不在盈利时提前止盈**（让利润奔跑）
- **不在情绪激动时交易**（连续亏损后强制休息 24 小时）
- **不违反既定规则**（即使"这次不一样"）

# 市场主线识别 SKILL

## 核心目标

从当日市场海量信息中提炼 3-8 条主线，每条主线包含：

- 主题名（2-6 字）
- 大类归属（科技 / 消费 / 周期 / 金融 / 医药 / 政策 / 其他）
- 叙事（1-2 句话故事线）
- 代表性标的（3-8 只 A 股）
- 强度评分（0-100）
- 持续性判断（1d / 1w / 1m / fading / emerging）

## 数据源

### 1. 热门股（get_hot_stocks）

- 按关注度 / 资金流入排序
- 识别资金抱团方向
- 关注前 20 只热门股所属行业

### 2. 财联社快讯（get_cls_flash）

- 实时新闻流（30 条最新）
- 提取关键词：政策 / 业绩 / 订单 / 事件
- 分类归集到对应主题

### 3. 龙虎榜（get_market_dragon_tiger）

- 游资 / 机构席位明细
- 识别主导资金类型
- 上榜股集中于某板块 → 板块强势信号

### 4. 北向资金（get_north_bound_flow）

- 沪股通 / 深股通净流入
- 行业分布（北向偏好蓝筹）
- 连续净流入行业 → 中长期主线

## 强度评分标准

| 维度     | 权重 | 评分依据                                                 |
| -------- | ---- | -------------------------------------------------------- |
| 涨停数   | 30%  | 板块涨停 ≥5 = 30 分；3-4 = 20 分；1-2 = 10 分            |
| 资金流入 | 25%  | 北向净流入 ≥10 亿 = 25 分；5-10 = 15 分；<5 = 5 分       |
| 龙头表现 | 20%  | 龙头涨停 = 20 分；龙头涨 > 5% = 15 分；龙头涨 > 0 = 5 分 |
| 持续性   | 15%  | 连续 3 日活跃 = 15 分；2 日 = 10 分；首日 = 5 分         |
| 新闻催化 | 10%  | 重大政策 / 业绩超预期 = 10 分；常规 = 5 分               |

**强度分级**：

- 80-100：强主线（满仓参与）
- 60-80：中等主线（半仓参与）
- 40-60：弱主线（观察 / 小仓位）
- <40：题材噪音（不参与）

## 持续性判断

| 标签       | 含义     | 判定条件                        |
| ---------- | -------- | ------------------------------- |
| `emerging` | 新兴主题 | 首日爆发，逻辑待验证            |
| `1d`       | 一日游   | 当日爆发但缺乏基本面支撑        |
| `1w`       | 一周     | 连续 3 日活跃，逻辑清晰         |
| `1m`       | 一月     | 连续 5 日活跃，机构资金持续流入 |
| `fading`   | 减退     | 前期活跃今日走弱，龙头回调      |

## 主线去重规则

1. 同日同主题只输出一条，合并代表性标的
2. 相似主题归并（如"AI 算力"和"光模块"可合并为"AI 算力链"）
3. 强度优先：强度高的主题覆盖强度低的同质主题

## 工具调用建议

- `get_hot_stocks`：热门股池
- `get_cls_flash`：快讯流（limit=30）
- `get_market_dragon_tiger`：龙虎榜
- `get_north_bound_flow`：北向资金
- `market_mainline_batch_upsert`：持久化到 market_mainlines 表

## 风险提示

- 主线强度评分依赖数据质量，单源数据可能失真
- 持续性判断是概率性预测，不保证 100% 准确
- 新兴主题（emerging）风险高，建议小仓位试错
- 减退主题（fading）禁止追高

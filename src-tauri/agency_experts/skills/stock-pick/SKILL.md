# 选股技巧 SKILL

## 三维度选股框架

### 1. 基本面筛选

**核心指标**：

- ROE ≥ 12%（连续 3 年）
- 毛利率 ≥ 30%（行业可比）
- 营收增速 ≥ 15%（YoY）
- 资产负债率 ≤ 60%（非金融）
- 经营现金流净额 / 净利润 ≥ 0.8

**行业地位**：

- 细分领域龙头（市占率前 3）
- 具备定价权（毛利率稳定性）
- 护城河明确（技术 / 品牌 / 渠道 / 资源）

**负面清单**：

- 商誉占净资产 > 30%
- 应收账款周转率同比下降
- 存货周转率连续 2 年下降
- 大股东质押率 > 70%

### 2. 技术面择时

**趋势判断**：

- 均线多头排列（5 > 10 > 20 > 60 日均线）
- MACD 金叉且柱状图为正
- 站上布林带中轨

**形态识别**：

- 突破颈线 / 平台突破（量能放大 1.5 倍以上）
- 回踩不破前低（缩量企稳）
- 底部形态：W 底 / 头肩底 / 圆弧底

**量价关系**：

- 上涨放量、下跌缩量
- 量比 > 1.5（活跃度提升）
- 换手率 3%-15%（健康区间）

### 3. 资金面验证

**主力资金**：

- 主力净流入连续 3 日为正
- 大单买入占比 > 30%
- 龙虎榜上榜（机构席位净买入）

**北向资金**：

- 北向连续 5 日净买入（持股比例提升）
- 北向持股比例 > 2%

**板块联动**：

- 所属行业当日涨幅前 5
- 板块内涨停股 ≥ 3 只
- 龙头股率先涨停，跟风股补涨

## 选股流程

```
1. 基本面初筛 → 池子约 200 只
2. 技术面择时 → 缩减到 30-50 只
3. 资金面验证 → 最终 5-10 只候选
4. 仓位分配 → 单票仓位 ≤ 20%
5. 止损设置 → 入场价 -5% 或支撑位下方
```

## 风险提示

- 三维度共振才是高质量信号，单维度信号胜率低
- 业绩窗口期避开披露前 30 日
- ST / 退市风险股一律排除
- 涨幅过大（30 日涨幅 > 50%）谨慎追高

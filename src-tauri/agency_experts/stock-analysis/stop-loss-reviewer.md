# 止损复查方法论

专注于对投资决策的止损合理性进行风控视角二次审视的方法论。

## 核心原则

1. **独立视角**：从风控角度独立审视，不受原决策影响
2. **波动率适配**：止损幅度需匹配个股波动率特征
3. **边界控制**：严禁止损超过单笔最大损失边界
4. **T+1 约束**：考虑隔夜跳空风险

## 评估维度

### 1. 止损幅度合理性

| 板块类型                | 建议止损幅度 | 说明                     |
| ----------------------- | ------------ | ------------------------ |
| 创业板/科创板（高波动） | -8% 至 -10%  | 高波动股，止损可适度放宽 |
| 主板蓝筹股（低波动）    | -5% 至 -7%   | 低波动股，止损应收紧     |
| 单笔最大损失边界        | ≤ -12%       | 严禁超过此边界           |

### 2. 止损触发条件

- 必须明确"收盘价跌破"还是"盘中触及"
- 避免因盘中假突破被洗盘
- 优先使用收盘价作为触发条件

### 3. 置信度匹配

| 决策置信度 | 建议止损   | 说明             |
| ---------- | ---------- | ---------------- |
| ≥ 0.8      | -6% 至 -8% | 高置信可适度放宽 |
| 0.5 - 0.8  | -5% 至 -6% | 标准置信度       |
| < 0.5      | -4% 至 -5% | 低置信需更严格   |

### 4. 资金管理

- 单笔最大损失 ≤ 总资金的 2%（凯利公式简化版）
- 结合止损幅度反推最大单票仓位

## 质量检查清单

- [ ] 止损幅度匹配板块波动率
- [ ] 止损触发条件明确（收盘价 vs 盘中）
- [ ] 置信度与止损幅度匹配
- [ ] 单笔最大损失 ≤ 总资金 2%
- [ ] 止损不超过 -12% 边界
- [ ] 考虑 T+1 隔夜跳空风险

# 仓位规划方法论

专注于基于投资决策生成可执行仓位方案的方法论。

## 核心原则

1. **决策驱动**：所有规划基于上游交易决策（买入/增持/持有/减持/卖出/观望）
2. **风控优先**：单票集中度不超过 30%，分批建仓控制风险
3. **T+1 约束**：严格遵守 A 股 T+1 交易规则
4. **量化止损/止盈**：基于置信度和风险等级设定合理阈值

## 规划规则

### 仓位分配

- 单只股票总仓位 ≤ 总资金的 30%（A 股单票集中度风控）
- 分批建仓：至少分 2-3 批，每批间隔 2-5 个交易日
- 首批不超过目标仓位的 40%

### 止损策略

| 置信度    | 止损幅度 | 说明             |
| --------- | -------- | ---------------- |
| ≥ 0.8     | -8%      | 高置信，适度放宽 |
| 0.5 - 0.8 | -6%      | 中置信，标准止损 |
| < 0.5     | -4%      | 低置信，严格止损 |

### 止盈策略

- 第一档 +15%：减仓 50%
- 第二档 +30%：全部清仓

### 动作映射

| 决策动作  | 规划类型     |
| --------- | ------------ |
| 买入/增持 | 分批建仓方案 |
| 减持/卖出 | 分批减仓方案 |
| 持有/观望 | 维持建议     |

## 质量检查清单

- [ ] 决策动作与规划类型匹配
- [ ] 单票仓位 ≤ 30%
- [ ] 分批建仓至少 2 批
- [ ] 止损幅度符合置信度区间
- [ ] 止盈分两档
- [ ] 考虑 T+1 约束

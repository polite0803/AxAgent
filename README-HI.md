**AxAgent** Tauri 2 पर आधारित एक क्रॉस-प्लेटफ़ॉर्म AI डेस्कटॉप क्लाइंट है (Windows / macOS / Linux / Android / iOS), जिसे AI-संचालित दैनिक विकास, शोध, ज्ञान प्रबंधन और स्वचालन वर्कबेंच के रूप में तैयार किया गया है। इसमें निर्मित ReAct एजेंट इंजन, संज्ञानात्मक रूटिंग (तीन-स्तरीय पदानुक्रमित रूटिंग + पुनर्प्राप्ति-वर्धित रूटिंग RAR), विज़ुअल वर्कफ़्लो ऑर्केस्ट्रेशन, स्थानीय RAG ज्ञान आधार, MCP प्रोटोकॉल विस्तार, बहु-मॉडल यूनिफ़ाइड गेटवे, ब्राउज़र स्वचालन और कंप्यूटर नियंत्रण जैसी क्षमताएँ शामिल हैं, जो AI को "बातचीत" से "निष्पादन" की ओर ले जाती हैं।

## परियोजना का उद्देश्य

AxAgent तीन मुख्य समस्याओं का समाधान करता है:

1. **बहु-मॉडल एकीकृत पहुँच और बुद्धिमान शेड्यूलिंग** — एक ही इंटरफ़ेस में OpenAI, Anthropic Claude, Google Gemini, DeepSeek, Qwen, GLM, Kimi, 文心 (Wenxin), Ollama स्थानीय मॉडल और किसी भी OpenAI-संगत API का उपयोग; मल्टी-Key कोटा स्वचालित रोटेशन, कार्य-प्रकार के अनुसार बुद्धिमान रूटिंग और स्ट्रीमिंग तुलना का समर्थन
2. **AI का बातचीत से निष्पादन तक का बंद लूप** — 163+ निर्मित उपकरण + विज़ुअल वर्कफ़्लो + MCP विस्तार + ब्राउज़र/कंप्यूटर नियंत्रण; AI फ़ाइलें संचालित कर सकता है, कोड चला सकता है, Git प्रबंधित कर सकता है और कार्य शेड्यूल कर सकता है
3. **स्थानीय-प्रथम डेटा संप्रभुता** — बातचीत रिकॉर्ड, ज्ञान आधार, स्मृति और कॉन्फ़िगरेशन सभी स्थानीय SQLite डेटाबेस में संग्रहीत होते हैं; API Key AES-256-GCM एन्क्रिप्शन से सुरक्षित होते हैं; मुख्य कार्यक्षमता बिना किसी तृतीय-पक्ष क्लाउड सेवा के चल सकती है

## मुख्य क्षमताएँ

### संज्ञानात्मक रूटिंग प्रणाली (Cognitive Router)

AxAgent `cognitive_query` को सभी बातचीत का एकीकृत प्रवेश द्वार बनाता है, और **तीन-स्तरीय पदानुक्रमित रूटिंग** के माध्यम से उपयोगकर्ता के इरादे को विशिष्ट क्षमताओं से जोड़ता है:

- **L1 डोमेन रूटिंग** (`domain_router`): नियम + LLM फ़ॉलबैक, 9 प्रमुख व्यावसायिक डोमेन की पहचान (डेटा विश्लेषण / सामग्री निर्माण / संचार / ऑपरेशन / AI मीडिया / वित्त / स्वचालन / सामान्य आदि)
- **L2 क्लस्टर रूटिंग** (`cluster_router`): डोमेन के भीतर क्षमता क्लस्टर की पहचान (27 क्लस्टर, 8 प्रमुख व्यावसायिक डोमेन को कवर करते हुए)
- **L3 क्षमता रूटिंग**: **पुनर्प्राप्ति-वर्धित रूटिंग (RAR)** — क्षमता वेक्टर डेटाबेस से Top-K समान वर्कफ़्लो को पुनर्प्राप्त करके Prompt में इंजेक्ट करता है, वर्कफ़्लो DAG ग्राफ़ पथ-खोज के साथ संयुक्त, पथ पता (जैसे `/finance/stock_analysis/tech`) और निष्पादन मोड आउटपुट करता है
- **निष्पादन मोड**: `Ask / Plan / Act / Workflow / Direct / Delegate / ParameterExtract / Clarify`, विश्वास-स्तर के अनुसार स्वचालित रूप से चुना जाता है
- **क्षमता प्रणाली**: एकीकृत रजिस्ट्री (`CapabilityRegistry`) + वेक्टर इंडेक्स (`CapabilityIndexer`) + हाइब्रिड पुनर्प्राप्ति (`CapabilityRetriever`, वेक्टर + BM25 + टैग हार्ड-मैच + नेगेटिव-नमूना बहिष्करण)
- **सिस्टम क्षमता पृथक्करण**: संज्ञानात्मक ऑर्केस्ट्रेटर और व्यावसायिक वर्कफ़्लो भौतिक रूप से अलग होते हैं; सिस्टम क्षमताएँ `SYSTEM_ONLY` दृश्यता चिह्न के साथ होती हैं; रूटिंग परत में आत्म-संदर्भ सर्किट-ब्रेकर निर्मित होता है, जो आत्म-संदर्भ विरोधाभास को रोकता है
- **तीन-स्तरीय रूटिंग वर्कफ़्लो DAG के रूप में लागू**: 4 पूर्व-निर्धारित रूटिंग वर्कफ़्लो टेम्पलेट (मुख्य ऑर्केस्ट्रेशन ~20 नोड + L1/L2/L3 उप-रूटिंग), `rt-workflow` इंजन द्वारा निष्पादित

### बहु-मॉडल इंजन

- **13 प्रदाता एडेप्टर**: OpenAI (Chat Completions + Responses + Realtime), Anthropic Claude, Google Gemini, DeepSeek, Qwen, GLM, Kimi, 文心一言 (Wenxin Yiyan), Ollama, Llama.cpp (GGUF स्थानीय मॉडल), OpenClaw, Hermes, साथ ही सभी OpenAI-संगत API
- **मल्टी-Key रोटेशन**: एक ही प्रदाता के कई API Key, कोटा के अनुसार स्वचालित रोटेशन; एकल Key पर रेट-लिमिट होने पर स्वचालित स्विच
- **बुद्धिमान रूटिंग**: कार्य-प्रकार (कोड समीक्षा / सारांश / अनुवाद / सामान्य) के अनुसार सर्वोत्तम मॉडल का स्वचालित चयन, कस्टम नियमों का समर्थन
- **प्रदाता स्वास्थ्य निगरानी**: सफलता दर, विलंबता और उपलब्धता स्थिति की वास्तविक समय में ट्रैकिंग; स्तरीय स्वचालित डिग्रेडेशन का समर्थन
- **AI छवि निर्माण**: DALL-E 3 और Flux मल्टी-साइज़ प्रीसेट
- **रियल-टाइम वॉइस**: OpenAI Realtime API पर आधारित WebSocket वॉइस बातचीत, व्यवधान (interruption) और स्ट्रीमिंग ट्रांसक्रिप्शन के समर्थन के साथ

### एजेंट प्रणाली (ReAct इंजन)

- **पदानुक्रमित प्लानर** (`hierarchical_planner`): जटिल कार्यों को Phase → Task संरचित योजना में विभाजित करता है, DAG टोपोलॉजिकल निष्पादन में संकलित करता है
- **गहन शोध** (`deep_research`): बहु-स्रोत खोज ऑर्केस्ट्रेशन, जिसमें खोज योजना, खोज निष्पादन, सामग्री संश्लेषण और उद्धरण ट्रैकिंग शामिल है
- **तथ्य-जाँच** (`fact_checker`): AI-संचालित तथ्य सत्यापन, जिसमें स्रोत वर्गीकरणकर्ता और विश्वसनीयता मूल्यांकन शामिल है
- **विचार-वृक्ष** (`tree_of_thoughts`): बहु-पथ तर्क अन्वेषण, शाखा मूल्यांकन और बैकट्रैकिंग
- **रिफ्लेक्टर** (`reflector`): कार्य निष्पादन के बाद आत्म-मूल्यांकन और सुधार सुझाव
- **स्व-सत्यापन** (`self_verifier`): तर्क परिणामों का स्वचालित सत्यापन, लूप डिटेक्शन सहित
- **त्रुटि पुनर्प्राप्ति** (`error_recovery_engine`): त्रुटि-प्रकार वर्गीकरण → पुनर्प्राप्ति रणनीति चयन → स्वचालित पुनः प्रयास या योजना समायोजन, एक्सपोनेंशियल बैकऑफ़ के समर्थन के साथ
- **A/B परीक्षण** (`ab_testing`): विभिन्न तर्क रणनीतियों का तुलनात्मक मूल्यांकन
- **मूल्यांकन प्रणाली** (`evaluator`): निर्मित बेंचमार्क परीक्षण फ्रेमवर्क
- **LoRA फ़ाइन-ट्यूनिंग** (`fine_tune`): निर्मित प्रशिक्षण पाइपलाइन, LoRA एडेप्टर प्रबंधन का समर्थन
- **RL ऑप्टिमाइज़र** (`rl_optimizer`): अनुभव-प्रतिक्रिया पर आधारित नीति सुदृढ़ीकरण अधिगम

**बहु-एजेंट सहयोग**:

- मास्टर-स्लेव समन्वय आर्किटेक्चर, उप-एजेंट समानांतर निष्पादन, निर्भरता-जागरूक शेड्यूलिंग
- एजेंटों के बीच सूचना विनिमय के लिए साझा ब्लैकबोर्ड
- प्रतिकूल बहस मोड (Pro/Con राउंड और तर्क-शक्ति स्कोरिंग)
- Swarm क्लस्टर मोड, बहु-प्रक्रिया एजेंट क्लस्टर
- सक्रिय मोड: एजेंट सक्रिय रूप से सुझाव और क्रियाएँ शुरू कर सकते हैं

**कंप्यूटर नियंत्रण**: AI-संचालित माउस क्लिक, कीबोर्ड इनपुट, स्क्रीन स्क्रॉल; तीन-स्तरीय अनुमति (डिफ़ॉल्ट / संपादन स्वीकारें / पूर्ण पहुँच), सैंडबॉक्स पथ पृथक्करण

**ब्राउज़र स्वचालन**: CDP प्रोटोकॉल के माध्यम से ब्राउज़र नियंत्रण, नेविगेशन, स्क्रीनशॉट, क्लिक, फ़ॉर्म भरना और टेक्स्ट निष्कर्षण का समर्थन

### कौशल प्रणाली

- **कौशल बाज़ार**: सामुदायिक कौशल ब्राउज़ करें और इंस्टॉल करें
- **AI-सहायित निर्माण**: प्राकृतिक भाषा प्रस्ताव से स्वचालित रूप से कौशल संरचना बनाएँ (`skill:create`)
- **कौशल विकास** (`evolution_engine`): निष्पादन प्रतिक्रिया के आधार पर कौशल का स्वचालित विश्लेषण और सुधार
- **अर्थगत मिलान**: बातचीत के संदर्भ के आधार पर प्रासंगिक कौशल की स्वचालित अनुशंसा
- **कौशल विघटन** (`skill_decomposition`): जटिल कार्यों को परमाणु कौशल संयोजनों में स्वचालित रूप से विभाजित करना
- **उपकरण निर्माण**: AI नए उपकरण बनाता और पंजीकृत करता है
- **सैंडबॉक्स निष्पादन**: कौशल पृथक सैंडबॉक्स में सुरक्षित रूप से निष्पादित होते हैं

### विज़ुअल वर्कफ़्लो

ReactFlow 12 पर आधारित ड्रैग-एंड-ड्रॉप DAG वर्कफ़्लो संपादक:

- **32 प्रकार के नोड**: ट्रिगर, एजेंट, LLM कॉल, सशर्त शाखा, समानांतर फ़ोर्क, लूप, मर्ज, विलंब, टूल कॉल, कोड निष्पादन, उप-वर्कफ़्लो, वेक्टर पुनर्प्राप्ति, दस्तावेज़ पार्सिंग, सत्यापन, समाप्ति, HTTP अनुरोध, Switch, डेटाबेस क्वेरी, अधिसूचना, अनुमोदन, फ़ाइल संचालन, डेटा परिवर्तन, Webhook भेजना, लॉग, LLM क्लासिफ़ायर, एग्रीगेटर, ईमेल, बहस, Swarm, बहु-एजेंट, संग्रहण, व्यावसायिक नियम
- **Kahn टोपोलॉजिकल सॉर्ट निष्पादन**: चक्रीय निर्भरताओं का स्वचालित पता लगाना, समानांतर पाइपलाइन शेड्यूलिंग
- **निर्मित टेम्पलेट**: कोड समीक्षा, Bug फ़िक्स, दस्तावेज़ निर्माण, परीक्षण, रीफ़ैक्टरिंग, अन्वेषण, प्रदर्शन विश्लेषण, सुरक्षा समीक्षा, फ़ीचर विकास
- **YAML सीरियलाइज़ेशन**: वर्कफ़्लो परिभाषाओं का आयात/निर्यात
- **संस्करण प्रबंधन**: टेम्पलेट संस्करण नियंत्रण
- **AI-सहायित डिज़ाइन**: AI-सहायित वर्कफ़्लो डिज़ाइन, नोड अनुशंसा और निदान

### ज्ञान प्रबंधन

- **बहु-ज्ञान-आधार RAG**: दस्तावेज़ अपलोड → स्वचालित पार्सिंग (PDF/DOCX/XLSX/PPTX/TXT) → चंकिंग → वेक्टर इंडेक्सिंग
- **हाइब्रिड पुनर्प्राप्ति**: वेक्टर समानता (sqlite-vec + candle स्थानीय एम्बेडिंग) + BM25 पूर्ण-पाठ खोज (FTS5), हाइब्रिड रैंकिंग
- **Self-RAG**: पुनर्प्राप्ति परिणामों का स्वचालित प्रतिबिंब और सत्यापन
- **पुनः-रैंकिंग**: Cross-encoder परिणाम पुनः-रैंकिंग
- **ज्ञान ग्राफ़**: इकाई निष्कर्षण → संबंध निर्माण → विज़ुअल ग्राफ़
- **फ़ाइल निगरानी**: `notify` पर आधारित वास्तविक समय फ़ाइल परिवर्तन निगरानी, स्वचालित वृद्धिशील इंडेक्सिंग
- **LLM Wiki**: AI-सहायित Wiki संकलक और सत्यापनकर्ता

### स्मृति प्रणाली

- **बहु-नामस्थान स्मृति**: परियोजना/विषय के अनुसार पृथक्करण, मैनुअल प्रविष्टि और AI स्वचालित निष्कर्षण का समर्थन
- **स्थायी एकीकरण**: Honcho और Mem0 बंद-लूप स्मृति
- **उपयोगकर्ता प्रोफ़ाइल**: कोड शैली, तकनीकी स्टैक प्राथमिकताएँ और संचार शैली का स्वचालित अधिगम
- **शैली स्थानांतरण**: कोड शैली विशेषताएँ निकालना → AI-जनित कोड पर लागू करना
- **स्वप्न एकीकरण**: पृष्ठभूमि में स्मृति टुकड़ों और व्यवहार पैटर्न का स्वचालित एकीकरण, संरचित ज्ञान उत्पन्न करना
- **परियोजना स्मृति**: परियोजना-आयाम के अनुसार संदर्भ का स्थायीकरण

### API गेटवे

`axum` पर आधारित निर्मित HTTP + WebSocket गेटवे:

- **दर सीमा**: `governor` पर आधारित टोकन-बकेट एल्गोरिथ्म

### बैकएंड आर्किटेक्चर: Harness निर्भरता इंजेक्शन पैटर्न

Rust workspace आर्किटेक्चर अपनाया गया है, जिसमें **37 सदस्य** (मुख्य crate + 35 लाइब्रेरी crate + schema-gen) शामिल हैं, और **Harness निर्भरता इंजेक्शन आर्किटेक्चर** का पालन करता है:

> सभी crate axagent-harness में परिभाषित trait इंटरफ़ेस के माध्यम से डिकपल होते हैं; रनटाइम पर axagent-runtime द्वारा निर्भरताएँ असेंबल और इंजेक्ट की जाती हैं।
> निर्भरता दिशा: `विशिष्ट कार्यान्वयन → harness ← कॉलर`

**harness** आर्किटेक्चर की आधारशिला है — शून्य व्यावसायिक तर्क, शून्य विशिष्ट कार्यान्वयन, केवल trait परिभाषाएँ, शुद्ध डेटा DTO, स्थिरांक और एकीकृत त्रुटि प्रकार। इस पर सभी अन्य crate निर्भर होते हैं, और यह स्वयं किसी भी axagent-* crate पर निर्भर नहीं होता (200+ trait परिभाषाएँ, जिनमें Agent/Provider/Tool/RAG/संग्रहण/MCP/प्लगइन/सुरक्षा/अवलोकनीयता/स्मृति/अधिगम/ब्राउज़र/संदेश/संज्ञानात्मक रूटिंग आदि शामिल हैं)।

## त्वरित आरंभ

### पर्यावरण आवश्यकताएँ

- [Node.js](https://nodejs.org/) 20+
- [Rust](https://www.rust-lang.org/) 1.75+ (edition 2024)
- [npm](https://www.npmjs.com/) 10+
- Windows: [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (MSVC + Windows SDK)
- macOS: Xcode Command Line Tools
- Linux: `build-essential` + `libwebkit2gtk-4.1-dev` + `libssl-dev`

### विकास

```bash
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent
npm install
npm run tauri dev      # विकास मोड (फ्रंटएंड Vite HMR + Tauri विंडो)
```

### निर्माण

```bash
npm run tauri build    # डेस्कटॉप प्रोडक्शन बिल्ड

npm run tauri:android:build   # Android बिल्ड
npm run tauri:ios:build       # iOS बिल्ड
```

डेस्कटॉप बिल्ड आउटपुट `src-tauri/target/release/` में स्थित होता है।

### परीक्षण

```bash
npm run test           # फ्रंटएंड यूनिट परीक्षण (Vitest watch)
npm run test:run       # फ्रंटएंड यूनिट परीक्षण (एकल रन)
npm run test:e2e       # E2E परीक्षण (Playwright)

# Rust बैकएंड परीक्षण
cd src-tauri && cargo test

# प्रकार जाँच और Lint
npm run typecheck
cd src-tauri && cargo clippy -- -D warnings
npm run format         # dprint फ़ॉर्मेटिंग
npm run lint:eslint    # ESLint जाँच
npm run contracts      # API अनुबंध जाँच

# CI पूर्ण जाँच
npm run ci:check
```

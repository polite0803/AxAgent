## AxAgent क्या हल करता है

AxAgent तीन मुख्य समस्याओं को हल करता है:

1. **एकीकृत मल्टी-मॉडल ऑर्केस्ट्रेशन**: OpenAI, Anthropic Claude, Google Gemini, Ollama स्थानीय मॉडल और किसी भी OpenAI-संगत API का एकल इंटरफ़ेस में उपयोग करें, मल्टी-की रोटेशन, बुद्धिमान मॉडल राउटिंग और स्ट्रीमिंग तुलना के साथ
2. **AI क्षमता का ऑपरेशनलीकरण**: AI को "बातचीत" से "निष्पादन" तक विस्तारित करें — 47+ अंतर्निहित उपकरणों, विज़ुअल वर्कफ़्लो, MCP एक्सटेंशन, ब्राउज़र ऑटोमेशन और कंप्यूटर नियंत्रण के माध्यम से AI सीधे फ़ाइलों में हेरफेर कर सकता है, कोड चला सकता है, Git प्रबंधित कर सकता है और कार्यों को शेड्यूल कर सकता है
3. **स्थानीय-प्राथमिक डेटा संप्रभुता**: AI वार्तालाप, नॉलेज बेस, मेमोरी और कॉन्फ़िगरेशन फ़ाइलें सभी स्थानीय SQLite डेटाबेस में संग्रहीत हैं। API कुंजियों को AES-256-GCM के साथ एन्क्रिप्ट किया जाता है। मुख्य कार्यक्षमता किसी तृतीय-पक्ष क्लाउड सेवा के बिना चलती है।

## मुख्य क्षमताएँ

### मल्टी-मॉडल इंजन

- **9 प्रदाता एडैप्टर**: OpenAI (Chat Completions + Responses + Realtime), Anthropic Claude, Google Gemini, Ollama (GGUF प्रबंधन के साथ), OpenClaw, Hermes और सभी OpenAI-संगत API
- **मल्टी-की रोटेशन**: कोटा-आधारित स्वचालित रोटेशन के साथ प्रति प्रदाता कई API कुंजियाँ कॉन्फ़िगर करें ताकि रेट-लिमिट बाधाओं से बचा जा सके
- **बुद्धिमान राउटिंग**: कार्य प्रकार (कोड समीक्षा / सारांश / अनुवाद / सामान्य) के अनुसार सबसे उपयुक्त मॉडल का स्वचालित चयन, अनुकूलनीय राउटिंग नियमों के साथ
- **प्रदाता स्वास्थ्य निगरानी**: प्रति प्रदाता सफलता दर, विलंब और उपलब्धता का वास्तविक समय ट्रैकिंग, टायर-आधारित स्वचालित फ़ॉलबैक (ProviderTier)
- **AI छवि जनरेशन**: DALL-E 3 और Flux (Replicate) कई आकार प्रीसेट के साथ
- **रियल-टाइम वॉयस**: OpenAI Realtime API पर आधारित WebSocket वॉयस कन्वर्सेशन, बाधा और स्ट्रीमिंग ट्रांसक्रिप्शन के समर्थन के साथ

### एजेंट सिस्टम

पूरा एजेंट सिस्टम **ReAct (Reasoning + Acting) इंजन** पर आधारित है, जिसमें निम्नलिखित कार्यान्वित उप-प्रणालियाँ शामिल हैं:

- **हायरार्किकल प्लानर** (`hierarchical_planner`): जटिल कार्यों को निर्भरता संबंधों के साथ Phase → Task संरचित योजनाओं में विघटित करता है, जिन्हें DAG टोपोलॉजिकल निष्पादन में संकलित किया जाता है
- **डीप रिसर्च** (`deep_research`): मल्टी-सोर्स सर्च ऑर्केस्ट्रेशन जिसमें सर्च प्लानिंग (`search_planner`), सर्च एक्जीक्यूशन (`search_orchestrator`), कंटेंट सिंथेसिस (`content_synthesizer`) और साइटेशन ट्रैकिंग (`citation_tracker`) शामिल हैं
- **फैक्ट चेकर** (`fact_checker`): सोर्स क्लासिफायर (`source_classifier`), सोर्स वैलिडेटर (`source_validator`) और क्रेडिबिलिटी एवैलुएटर (`credibility_evaluator`) के साथ AI-संचालित तथ्य सत्यापन
- **ट्री ऑफ़ थॉट्स** (`tree_of_thoughts`): शाखा मूल्यांकन और बैकट्रैकिंग के साथ मल्टी-पाथ रीज़निंग एक्सप्लोरेशन
- **रिफ्लेक्टर** (`reflector`): कार्य के बाद स्व-मूल्यांकन और सुधार सुझाव
- **सेल्फ-वेरिफायर** (`self_verifier`): साइकिल डिटेक्शन (`cycle_detector`) के साथ रीज़निंग परिणामों का स्वचालित सत्यापन ताकि इन्फिनिट लूप से बचा जा सके
- **एरर रिकवरी** (`error_recovery_engine`): एरर प्रकार वर्गीकरण → रिकवरी रणनीति चयन → ऑटो-रिट्राई या प्लान एडजस्ट, एक्सपोनेंशियल बैकऑफ़ के साथ
- **A/B टेस्टिंग** (`ab_testing`): विभिन्न रीज़निंग रणनीतियों का तुलनात्मक मूल्यांकन
- **इवैलुएशन सिस्टम** (`evaluator`): डेटासेट, मेट्रिक्स और रिपोर्ट जनरेशन के समर्थन के साथ अंतर्निहित बेंचमार्क फ्रेमवर्क
- **LoRA फाइन-ट्यूनिंग** (`fine_tune`): LoRA एडैप्टर प्रबंधन के साथ अंतर्निहित ट्रेनिंग पाइपलाइन
- **RL ऑप्टिमाइज़र** (`rl_optimizer`): एक्सपीरियंस रिप्ले और पॉलिसी ग्रेडिएंट्स के साथ अनुभव-फीडबैक-आधारित पॉलिसी रिनफ़ोर्समेंट लर्निंग
- **टूल रिकमेंडर** (`tool_recommender`): संदर्भ-आधारित टूल उपयोग पैटर्न विश्लेषण और अनुशंसाएँ

**मल्टी-एजेंट सहयोग**:

- मास्टर-स्लेव समन्वय आर्किटेक्चर (`coordinator`) समानांतर सब-एजेंट एक्जीक्यूशन और निर्भरता-जागरूक शेड्यूलिंग के साथ
- इंटर-एजेंट सूचना विनिमय के लिए साझा ब्लैकबोर्ड (`shared_blackboard`)
- प्रो/कॉन राउंड और तर्क शक्ति स्कोरिंग के साथ प्रतिद्वंद्वी बहस मोड
- अनुमति सिंक और ऑटो-रिकनेक्ट का समर्थन करने वाले मल्टी-प्रोसेस एजेंट क्लस्टर्स के साथ स्वार्म क्लस्टर मोड
- प्रोएक्टिव मोड (`proactive_mode`): एजेंट सक्रिय रूप से सुझाव और कार्य प्रस्तावित कर सकते हैं

**कंप्यूटर नियंत्रण**: तीन-स्तरीय अनुमतियों (Default / Accept Edits / Full Access) और सैंडबॉक्स पाथ आइसोलेशन के साथ AI-संचालित माउस क्लिक, कीबोर्ड इनपुट, स्क्रीन स्क्रॉलिंग

**ब्राउज़र ऑटोमेशन**: CDP प्रोटोकॉल के माध्यम से ब्राउज़र नियंत्रण, नेविगेशन, स्क्रीनशॉट, क्लिक, फॉर्म भरने, टेक्स्ट एक्सट्रैक्शन और पेज स्टेट मॉनिटरिंग के समर्थन के साथ

### स्किल सिस्टम

- **स्किल मार्केटप्लेस**: कम्युनिटी स्किल्स ब्राउज़ और इंस्टॉल करें
- **AI-सहायता प्राप्त निर्माण**: प्राकृतिक भाषा प्रस्तावों से स्किल संरचनाओं का स्वचालित निर्माण
- **स्किल इवोल्यूशन** (`evolution_engine`): एक्जीक्यूशन फीडबैक के आधार पर स्किल्स का स्वचालित विश्लेषण और सुधार
- **सेमांटिक मैचिंग** (`skill`): वार्तालाप संदर्भ के आधार पर संबंधित स्किल्स का सेमांटिक मैचिंग और ऑटो-रिकमेंडेशन
- **स्किल डिकंपोज़िशन** (`skill_decomposition`): जटिल कार्यों का परमाणु स्किल संयोजनों में स्वचालित विघटन
- **जेनरेटेड टूल** (`generated_tool`): AI द्वारा जेनरेट और रजिस्टर किए गए नए टूल
- **सैंडबॉक्स एक्जीक्यूशन** (`sandbox`): स्किल्स पृथक सैंडबॉक्स वातावरण में सुरक्षित रूप से निष्पादित होते हैं

### विज़ुअल वर्कफ़्लो

ReactFlow 12 पर आधारित ड्रैग-एंड-ड्रॉप DAG वर्कफ़्लो एडिटर:

- **17 नोड प्रकार**: Trigger, Agent, LLM Call, Conditional Branch, Parallel Fork, Loop, Merge, Delay, Tool Call, Code Execution, Sub-workflow, Vector Retrieval, Document Parsing, Validation, End, Business Rule, Agent Role
- **Kahn टोपोलॉजिकल सॉर्ट एक्जीक्यूशन**: पैरलल पाइपलाइन शेड्यूलिंग के साथ स्वचालित साइक्लिक डिपेंडेंसी डिटेक्शन
- **अंतर्निहित टेम्पलेट्स**: Code Review, Bug Fix, Document Generation, Testing, Refactoring, Exploration, Performance Analysis, Security Audit, Feature Development
- **YAML सीरियलाइज़ेशन**: वर्कफ़्लो परिभाषाएँ YAML इम्पोर्ट/एक्सपोर्ट का समर्थन करती हैं
- **वर्शन प्रबंधन**: वर्कफ़्लो टेम्पलेट वर्शन कंट्रोल
- **AI सहायता**: AI-सहायता प्राप्त वर्कफ़्लो डिज़ाइन और नोड अनुशंसाएँ

### नॉलेज मैनेजमेंट

- **मल्टी-KB RAG**: डॉक्यूमेंट अपलोड → ऑटो पार्सिंग (PDF/DOCX/XLSX/PPTX/TXT) → चंकिंग → वेक्टर इंडेक्सिंग
- **हाइब्रिड रिट्रीवल**: वेक्टर समानता (sqlite-vec + candle स्थानीय एम्बेडिंग्स) + BM25 फुल-टेक्स्ट सर्च (FTS5) हाइब्रिड रैंकिंग के साथ
- **Self-RAG**: स्वचालित रिट्रीवल परिणाम रिफ्लेक्शन और वेरिफिकेशन के साथ स्व-रिट्रीवल-आधारित जनरेशन
- **Re-ranking**: बेहतर सटीकता के लिए Cross-encoder रिजल्ट री-रैंकिंग
- **नॉलेज ग्राफ**: एंटिटी एक्सट्रैक्शन (`EntityExtractor`) → रिलेशनशिप कंस्ट्रक्शन → विज़ुअल ग्राफ
- **फ़ाइल वॉचिंग**: `notify` के माध्यम से वास्तविक समय फ़ाइल परिवर्तन मॉनिटरिंग के साथ स्वचालित इंक्रीमेंटल इंडेक्सिंग
- **LLM Wiki**: Wiki क्लिपिंग ब्राउज़र एक्सटेंशन के साथ AI-सहायता प्राप्त Wiki कंपाइलर और वैलिडेटर

### मेमोरी सिस्टम

- **मल्टी-नेमस्पेस मेमोरी**: प्रोजेक्ट/विषय द्वारा अलग, मैनुअल इनपुट और AI ऑटो-एक्सट्रैक्शन दोनों का समर्थन
- **पर्सिस्टेंस इंटीग्रेशन**: Honcho और Mem0 क्लोज़्ड-लूप मेमोरी
- **यूज़र प्रोफ़ाइल** (`user_profile` / `profile`): कोडिंग स्टाइल (इंडेंटेशन/नेमिंग/कमेंट्स), टेक स्टैक प्राथमिकताओं और कम्युनिकेशन स्टाइल का ऑटो-लर्निंग
- **स्टाइल ट्रांसफ़र** (`style`): कोड स्टाइल फ़ीचर्स एक्सट्रैक्ट → AI-जेनरेटेड कोड पर लागू करें
- **ड्रीम इंटीग्रेशन** (`dream`): मेमोरी फ़्रैगमेंट्स और बिहेवियर पैटर्न्स का बैकग्राउंड में स्वचालित कंसॉलिडेशन स्ट्रक्चर्ड नॉलेज में
- **प्रोजेक्ट मेमोरी** (`project_memory`): प्रति-प्रोजेक्ट कॉन्टेक्स्ट पर्सिस्टेंस

### API गेटवे

`axum` पर आधारित अंतर्निहित HTTP + WebSocket गेटवे सर्वर:

- **संगत एंडपॉइंट्स**: OpenAI `/v1/chat/completions`, Claude Messages API, Gemini API, साथ ही OpenAI Responses और Realtime WebSocket
- **की मैनेजमेंट**: एक्सपायरी समर्थन के साथ एक्सेस कीजनरेट, रिवोक, एनेबल/डिसेबल करें
- **उपयोग ट्रैकिंग**: प्रति-की, प्रति-प्रदाता, प्रति-तारीख अनुरोध गणना और टोकन उपभोग आँकड़े Prometheus मेट्रिक्स एक्सपोर्ट के साथ
- **रेट लिमिटिंग**: `governor` के माध्यम से Token bucket एल्गोरिदम, कॉन्फ़िगर योग्य रेट लिमिट पॉलिसीज़ के साथ
- **SSL/TLS**: अंतर्निहित सेल्फ-साइनड सर्टिफ़िकेट्स (`rcgen`) कस्टम सर्टिफ़िकेट समर्थन के साथ
- **एक्सटर्नल लिंकिंग**: क्लॉड CLI, OpenCode और अन्य एक्सटर्नल टूल्स के साथ वन-क्लिक इंटीग्रेशन, ऑटो API की सिंक के साथ
- **रियल-टाइम टिकट्स**: सुरक्षित WebSocket रियल-टाइम कनेक्शन हैंडऑफ़ के लिए HMAC-आधारित अस्थायी ऑथेंटिकेशन टिकट्स

### मैसेजिंग प्लैटफ़ॉर्म इंटीग्रेशन

`rt-messaging` crate के माध्यम से लागू मैसेजिंग प्लैटफ़ॉर्म गेटवे, समर्थन:

DingTalk, Feishu, QQ, Slack, WeChat, WhatsApp, Telegram, Discord

Webhook संदेश प्राप्ति, कमांड पार्सिंग और स्वचालित AI उत्तर वितरण का समर्थन करता है।

### MCP प्रोटोकॉल

`rmcp` crate पर आधारित MCP (Model Context Protocol) का पूर्ण कार्यान्वयन:

- **ट्रांसपोर्ट लेयर**: stdio सबप्रोसेस + Streamable HTTP + WebSocket
- **OAuth ऑथेंटिकेशन**: MCP सर्वर के लिए OAuth अधिकृतता प्रवाह समर्थन
- **टूल डिस्कवरी**: MCP सर्वर द्वारा उजागर किए गए टूल्स का स्वचालित पता लगाना और रजिस्टर करना
- **MCP मैनेजर**: सर्वर लाइफसाइकल मैनेजमेंट, हेल्थ चेक, ऑटो-रिकनेक्ट

### सुरक्षा

- **AES-256-GCM एन्क्रिप्शन**: API कीज और संवेदनशील कॉन्फ़िगरेशन के लिए स्थानीय एन्क्रिप्टेड स्टोरेज (`crypto` crate)
- **Prompt Injection Protection**: चार-स्तरीय डिफेंस पाइपलाइन (`prompt-guard`) — पैटर्न डिटेक्शन → डिलिमिटर एस्केपिंग → XML रैपर → ट्रस्ट लेबल्स, सत्र, प्रॉम्प्ट कंस्ट्रक्शन, Git और RAG में पूरी पाइपलाइन में एकीकृत
- **SSRF Protection** (`ssrf_guard`): आंतरिक नेटवर्क पतों पर अनुरोधों को ब्लॉक करने वाली URL सुरक्षा जाँच
- **कंटेंट फ़िल्टरिंग** (`content_filter`): मल्टी-टाइप कंटेंट सेफ्टी फ़िल्टरिंग
- **रेट लिमिटिंग** (`rate_limiter`): टूल कॉल्स और API अनुरोधों के लिए Token bucket रेट लिमिटिंग
- **सर्किट ब्रेकर** (`circuit_breaker`): सिस्टम स्थिरता की रक्षा के लिए लगातार विफलताओं पर स्वचालित सर्किट-ब्रेकिंग
- **एक्सेस कंट्रोल** (`tool_access`): पॉलिसी-आधारित टूल एक्सेस परमिशन कंट्रोल
- **सैंडबॉक्स आइसोलेशन**: एजेंट्स और स्किल्स के लिए एक्जीक्यूशन एनवायरनमेंट आइसोलेशन

### बैकएंड आर्किटेक्चर: Harness डिपेंडेंसी इंजेक्शन पैटर्न

बैकएंड **32 crates** के साथ एक Rust workspace आर्किटेक्चर का उपयोग करता है, जो **Harness Architecture Pattern** का पालन करता है:

```
सभी crates axagent-harness में परिभाषित trait इंटरफेस के माध्यम से डिकपल्ड हैं।
रनटाइम (axagent-runtime) रनटाइम पर डिपेंडेंसीज़ को असेंबल और इंजेक्ट करता है।

डिपेंडेंसी दिशा: कंक्रीट इम्प्लीमेंटेशन्स → harness ← कॉलर्स
```

**harness** आर्किटेक्चर का कोना-स्तंभ है — शून्य बिज़नेस लॉजिक, शून्य कंक्रीट इम्प्लीमेंटेशन्स, केवल trait परिभाषाएँ, शुद्ध डेटा DTO, कॉन्स्टेंट्स और एकीकृत एरर टाइप्स। अन्य सभी crates इस पर निर्भर करते हैं और यह किसी अन्य axagent-* crate पर निर्भर नहीं करता।

## क्विक स्टार्ट

### आवश्यकताएँ

- [Node.js](https://nodejs.org/) 20+
- [Rust](https://www.rust-lang.org/) 1.75+, edition 2024
- [npm](https://www.npmjs.com/) 10+
- Windows: [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (MSVC + Windows SDK)
- macOS: Xcode Command Line Tools
- Linux: `build-essential` + `libwebkit2gtk-4.1-dev` + `libssl-dev`

### बिल्ड

```bash
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent
npm install
npm run tauri dev      # डेवलपमेंट मोड
npm run tauri build    # प्रोडक्शन बिल्ड
```

बिल्ड आर्टिफैक्ट्स `src-tauri/target/release/` में स्थित हैं।

### टेस्टिंग

```bash
npm run test           # फ़्रंटएंड यूनिट टेस्ट (Vitest watch)
npm run test:run       # फ़्रंटएंड यूनिट टेस्ट (single run)
npm run test:e2e       # E2E टेस्ट (Playwright)

# Rust बैकएंड टेस्ट
cd src-tauri && cargo nextest run
cd src-tauri && cargo test

# टाइप चेकिंग और लिंटिंग
npm run typecheck
cd src-tauri && cargo clippy -- -D warnings
npm run format

# CI फुल चेक
npm run ci:check
```

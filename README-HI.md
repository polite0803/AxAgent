## परियोजना स्थिति

AxAgent तीन मुख्य समस्याओं का समाधान करता है:

1. **एकीकृत मल्टी-मॉडल एक्सेस और इंटेलिजेंट रूटिंग** — एक ही इंटरफ़ेस में OpenAI, Anthropic Claude, Google Gemini, Ollama लोकल मॉडल और किसी भी OpenAI-संगत API का उपयोग, मल्टी-की कोटा रोटेशन, कार्य प्रकार के अनुसार इंटेलिजेंट रूटिंग और स्ट्रीमिंग तुलना के साथ
2. **AI का बातचीत से निष्पादन तक बंद लूप** — 47+ अंतर्निहित टूल + विज़ुअल वर्कफ़्लो + MCP एक्सटेंशन + ब्राउज़र/कंप्यूटर कंट्रोल, AI फ़ाइल संचालन, कोड निष्पादन, Git प्रबंधन और कार्य शेड्यूलिंग कर सकता है
3. **लोकल-फर्स्ट डेटा संप्रभुता** — बातचीत, नॉलेज बेस, मेमोरी और कॉन्फ़िगरेशन सभी लोकल SQLite डेटाबेस में संग्रहीत, API कीज़ AES-256-GCM से एन्क्रिप्टेड। तृतीय-पक्ष क्लाउड सेवाओं के बिना मुख्य कार्यक्षमता संचालित

## मुख्य क्षमताएँ

### मल्टी-मॉडल इंजन

- **9 प्रदाता एडाप्टर**: OpenAI (Chat Completions + Responses + Realtime), Anthropic Claude, Google Gemini, Ollama (GGUF लोकल मॉडल प्रबंधन के साथ), OpenClaw, Hermes और सभी OpenAI-संगत API
- **मल्टी-की रोटेशन**: प्रति प्रदाता कई API कीज़, कोटा-आधारित स्वचालित रोटेशन, एकल-की सीमा पर स्वचालित फ़ेलओवर
- **इंटेलिजेंट रूटिंग**: कार्य प्रकार (कोड समीक्षा / सारांश / अनुवाद / सामान्य) के अनुसार स्वचालित मॉडल चयन, अनुकूलन योग्य नियम
- **प्रदाता स्वास्थ्य निगरानी**: सफलता दर, विलंबता और उपलब्धता की रीयल-टाइम ट्रैकिंग, स्तरित स्वचालित फ़ॉलबैक के साथ
- **AI छवि निर्माण**: DALL-E 3 और Flux (Replicate) मल्टी-साइज़ प्रीसेट के साथ
- **रीयल-टाइम वॉइस**: OpenAI Realtime API पर आधारित WebSocket वॉइस वार्तालाप, रुकावट और स्ट्रीमिंग ट्रांसक्रिप्शन समर्थन के साथ

### एजेंट सिस्टम (ReAct इंजन)

- **पदानुक्रमित योजनाकार** (`hierarchical_planner`): जटिल कार्यों को चरण → कार्य संरचित योजनाओं में विघटित करना, DAG टोपोलॉजिकल निष्पादन में संकलित
- **गहन अनुसंधान** (`deep_research`): मल्टी-सोर्स खोज ऑर्केस्ट्रेशन जिसमें खोज योजना, निष्पादन, सामग्री संश्लेषण और उद्धरण ट्रैकिंग शामिल है
- **तथ्य जाँचकर्ता** (`fact_checker`): AI-संचालित तथ्य सत्यापन जिसमें स्रोत वर्गीकरणकर्ता और विश्वसनीयता मूल्यांकन शामिल है
- **विचारों का वृक्ष** (`tree_of_thoughts`): मल्टी-पाथ तर्क अन्वेषण जिसमें शाखा मूल्यांकन और बैकट्रैकिंग शामिल है
- **परावर्तक** (`reflector`): निष्पादन के बाद आत्म-मूल्यांकन और सुधार सुझाव
- **स्व-सत्यापक** (`self_verifier`): तर्क परिणामों का स्वचालित सत्यापन, चक्र पहचान के साथ
- **त्रुटि पुनर्प्राप्ति** (`error_recovery_engine`): त्रुटि प्रकार वर्गीकरण → पुनर्प्राप्ति रणनीति → स्वचालित पुनः प्रयास या योजना समायोजन, घातीय बैकऑफ़ के साथ
- **A/B परीक्षण** (`ab_testing`): विभिन्न तर्क रणनीतियों का तुलनात्मक मूल्यांकन
- **मूल्यांकन प्रणाली** (`evaluator`): अंतर्निहित बेंचमार्क फ्रेमवर्क
- **LoRA फ़ाइन-ट्यूनिंग** (`fine_tune`): अंतर्निहित प्रशिक्षण पाइपलाइन, LoRA एडाप्टर प्रबंधन के साथ
- **RL ऑप्टिमाइज़र** (`rl_optimizer`): अनुभव प्रतिक्रिया-आधारित नीति सुदृढीकरण सीखना

**मल्टी-एजेंट सहयोग**:

- मास्टर-स्लेव समन्वय आर्किटेक्चर जिसमें उप-एजेंट समानांतर निष्पादन और निर्भरता-जागरूक शेड्यूलिंग शामिल है
- एजेंटों के बीच सूचना विनिमय के लिए साझा ब्लैकबोर्ड
- प्रतिकूल वाद-विवाद मोड (समर्थन/विरोध राउंड और तर्क शक्ति स्कोरिंग के साथ)
- मल्टी-प्रोसेस एजेंट क्लस्टर के लिए Swarm मोड
- सक्रिय मोड: एजेंट स्वचालित रूप से सुझाव और संचालन आरंभ कर सकते हैं

**कंप्यूटर कंट्रोल**: AI-संचालित माउस क्लिक, कीबोर्ड इनपुट, स्क्रीन स्क्रॉलिंग, तीन अनुमति स्तरों (डिफ़ॉल्ट / संपादन स्वीकार / पूर्ण पहुँच) और सैंडबॉक्स पथ पृथक्करण के साथ

**ब्राउज़र ऑटोमेशन**: CDP प्रोटोकॉल के माध्यम से ब्राउज़र नियंत्रण, नेविगेशन, स्क्रीनशॉट, क्लिक, फ़ॉर्म भरना और टेक्स्ट निष्कर्षण के साथ

### स्किल सिस्टम

- **स्किल मार्केटप्लेस**: समुदाय स्किल्स ब्राउज़ और इंस्टॉल करें
- **AI-सहायता निर्माण**: प्राकृतिक भाषा प्रस्तावों से स्वचालित स्किल संरचना निर्माण (`skill:create`)
- **स्किल इवोल्यूशन** (`evolution_engine`): निष्पादन प्रतिक्रिया के आधार पर स्वचालित स्किल विश्लेषण और सुधार
- **सिमेंटिक मिलान**: संदर्भ-जागरूक सिमेंटिक स्किल अनुशंसा
- **स्किल विघटन** (`skill_decomposition`): जटिल कार्यों का परमाणु स्किल संयोजनों में स्वचालित विघटन
- **उत्पन्न टूल**: AI-उत्पन्न और पंजीकृत नए टूल
- **सैंडबॉक्स निष्पादन**: स्किल्स पृथक सैंडबॉक्स वातावरण में निष्पादित होती हैं

### विज़ुअल वर्कफ़्लो

ReactFlow 12-आधारित ड्रैग-एंड-ड्रॉप DAG वर्कफ़्लो संपादक:

- **17 नोड प्रकार**: ट्रिगर, एजेंट, LLM कॉल, शर्तीय शाखा, समानांतर फ़ोर्क, लूप, मर्ज, विलंब, टूल कॉल, कोड निष्पादन, उप-वर्कफ़्लो, वेक्टर खोज, दस्तावेज़ पार्सिंग, सत्यापन, अंत, व्यावसायिक नियम, एजेंट भूमिका
- **Kahn टोपोलॉजिकल सॉर्ट निष्पादन**: स्वचालित चक्र पहचान, समानांतर पाइपलाइन शेड्यूलिंग
- **अंतर्निहित टेम्पलेट**: कोड समीक्षा, बग फ़िक्स, प्रलेखन, परीक्षण, रीफ़ैक्टरिंग, अन्वेषण, प्रदर्शन विश्लेषण, सुरक्षा ऑडिट, फ़ीचर विकास
- **YAML सीरियलाइज़ेशन**: वर्कफ़्लो परिभाषा आयात/निर्यात
- **संस्करण प्रबंधन**: टेम्पलेट संस्करण नियंत्रण
- **AI-सहायता डिज़ाइन**: AI-सहायता वर्कफ़्लो डिज़ाइन और नोड अनुशंसा

### ज्ञान प्रबंधन

- **मल्टी-नॉलेज बेस RAG**: दस्तावेज़ अपलोड → स्वचालित पार्सिंग (PDF/DOCX/XLSX/PPTX/TXT) → खंडन → वेक्टर अनुक्रमण
- **हाइब्रिड खोज**: वेक्टर समानता (sqlite-vec + candle लोकल एम्बेडिंग) + BM25 पूर्ण-पाठ खोज (FTS5), हाइब्रिड रैंकिंग
- **Self-RAG**: खोज परिणामों का स्वचालित परावर्तन और सत्यापन
- **पुनः-रैंकिंग**: क्रॉस-एनकोडर परिणाम पुनः-रैंकिंग
- **ज्ञान ग्राफ़**: इकाई निष्कर्षण → संबंध निर्माण → दृश्य ग्राफ़
- **फ़ाइल निगरानी**: `notify` के माध्यम से रीयल-टाइम फ़ाइल परिवर्तन निगरानी, स्वचालित वृद्धिशील अनुक्रमण
- **LLM Wiki**: AI-सहायता Wiki कंपाइलर और सत्यापनकर्ता

### मेमोरी सिस्टम

- **मल्टी-नेमस्पेस मेमोरी**: परियोजना/विषय पृथक्करण, मैनुअल इनपुट और AI स्वचालित निष्कर्षण
- **स्थायी एकीकरण**: Honcho और Mem0 बंद-लूप मेमोरी
- **उपयोगकर्ता प्रोफ़ाइल**: कोडिंग शैली, तकनीकी स्टैक प्राथमिकताएँ और संचार शैली का स्वचालित सीखना
- **शैली स्थानांतरण**: कोड शैली विशेषताओं का निष्कर्षण → AI-उत्पन्न कोड पर लागू करना
- **ड्रीम एकीकरण**: मेमोरी टुकड़ों और व्यवहार पैटर्न का स्वचालित पृष्ठभूमि समेकन, संरचित ज्ञान में
- **परियोजना मेमोरी**: परियोजना-स्तरीय संदर्भ स्थायित्व

### API गेटवे

`axum`-आधारित HTTP + WebSocket गेटवे अंतर्निहित:

- **संगत एंडपॉइंट**: OpenAI `/v1/chat/completions`, Claude Messages API, Gemini API, और OpenAI Responses व Realtime WebSocket
- **की प्रबंधन**: एक्सेस की जनरेशन, निरसन, सक्रिय/निष्क्रिय टॉगल, समाप्ति समर्थन के साथ
- **उपयोग ट्रैकिंग**: की/प्रदाता/दिनांक के अनुसार अनुरोध गणना और टोकन खपत सांख्यिकी, Prometheus मेट्रिक्स निर्यात
- **दर सीमा**: `governor` के माध्यम से टोकन बकेट एल्गोरिदम
- **SSL/TLS**: अंतर्निहित स्व-हस्ताक्षरित प्रमाणपत्र (`rcgen`), कस्टम प्रमाणपत्र समर्थन
- **बाहरी लिंकिंग**: Claude CLI, OpenCode और अन्य बाहरी टूल्स के साथ वन-क्लिक एकीकरण, स्वचालित API की सिंक
- **रीयल-टाइम टिकट**: HMAC-आधारित अस्थायी प्रमाणीकरण टिकट, WebSocket कनेक्शन के सुरक्षित हस्तांतरण के लिए

### मैसेजिंग प्लेटफ़ॉर्म एकीकरण

### MCP प्रोटोकॉल

`rmcp`-आधारित पूर्ण MCP (Model Context Protocol) कार्यान्वयन:

- **ट्रांसपोर्ट**: stdio सबप्रोसेस + Streamable HTTP + WebSocket
- **OAuth प्रमाणीकरण**: MCP सर्वर के लिए OAuth प्राधिकरण प्रवाह
- **टूल डिस्कवरी**: MCP सर्वर द्वारा उजागर टूल्स की स्वचालित खोज और पंजीकरण
- **MCP प्रबंधक**: सर्वर जीवनचक्र प्रबंधन, स्वास्थ्य जाँच, स्वचालित पुनः कनेक्शन

### प्लगइन सिस्टम

- npm पैकेज इंस्टॉलेशन, खोज और इंस्टॉलेशन के लिए मार्केटप्लेस UI के साथ

### सुरक्षा

- **AES-256-GCM एन्क्रिप्शन**: API कीज़ और संवेदनशील कॉन्फ़िगरेशन का लोकल एन्क्रिप्टेड स्टोरेज (`crypto` crate)
- **प्रॉम्प्ट इंजेक्शन सुरक्षा**: चार-स्तरीय रक्षा पाइपलाइन (`prompt-guard`) — पैटर्न पहचान → डेलिमीटर एस्केपिंग → XML रैपर → विश्वास लेबल, वार्तालाप/प्रॉम्प्ट निर्माण/Git/RAG श्रृंखला में एकीकृत
- **SSRF सुरक्षा**: आंतरिक नेटवर्क पतों पर अनुरोधों को रोकने के लिए URL सुरक्षा जाँच
- **सामग्री फ़िल्टरिंग**: मल्टी-टाइप सामग्री सुरक्षा फ़िल्टरिंग
- **दर सीमा**: टूल कॉल और API अनुरोधों के लिए टोकन बकेट सीमा
- **सर्किट ब्रेकर**: लगातार विफलताओं पर स्वचालित सर्किट ब्रेक
- **एक्सेस कंट्रोल**: नीति-आधारित टूल एक्सेस अनुमति नियंत्रण
- **सैंडबॉक्स पृथक्करण**: एजेंट और स्किल निष्पादन वातावरण पृथक्करण

### बैकएंड आर्किटेक्चर: Harness डिपेंडेंसी इंजेक्शन

Rust वर्कस्पेस आर्किटेक्चर, **32 crate**, **Harness DI** पैटर्न का पालन:

> सभी crate, axagent-harness द्वारा परिभाषित ट्रेट इंटरफ़ेस के माध्यम से डीकपल हैं, और axagent-runtime रनटाइम पर निर्भरताओं को असेंबल और इंजेक्ट करता है।
> निर्भरता दिशा: `ठोस कार्यान्वयन → harness ← कॉलर`

**harness** आर्किटेक्चरल आधारशिला है — शून्य व्यावसायिक तर्क, शून्य ठोस कार्यान्वयन, केवल ट्रेट परिभाषाएँ, शुद्ध डेटा DTO, स्थिरांक और एकीकृत त्रुटि प्रकार शामिल हैं। यह अन्य सभी crate द्वारा निर्भर है और स्वयं किसी भी axagent-* crate पर निर्भर नहीं है (200+ ट्रेट परिभाषाएँ, Agent/Provider/Tool/RAG/स्टोरेज/MCP/प्लगइन्स/सुरक्षा/ऑब्ज़र्वेबिलिटी/मेमोरी/लर्निंग/ब्राउज़र/मैसेजिंग आदि को कवर करती हैं)।

```
├── i18n/             # 11-भाषा अनुवाद फ़ाइलें (zh-CN/zh-TW/en-US/ja/ko/fr/de/es/ru/hi/ar)
├── constants/        # स्थिरांक और फ़ीचर फ़्लैग
└── sdk/              # बाहरी एकीकरण SDK
```

### फ़ीचर फ़्लैग

परियोजना `featureFlags.ts` के माध्यम से प्रगतिशील फ़ीचर रोलआउट प्रबंधित करती है:

| फ़्लैग                 | स्थिति | विवरण                                       |
| ------------------- | ----- | ------------------------------------------- |
| `AGENT_IN_THE_LOOP` | ✅    | ग्लोबल Agent पैनल + पृष्ठ संदर्भ इंजेक्शन            |
| `DYNAMIC_UI`        | ✅    | डायनेमिक UI बिल्डर इंजन                        |
| `SELF_EVOLUTION_UI` | ❌    | स्व-विकास फ्रंटएंड नियंत्रण पैनल                   |
| `NL_EXTENSION`      | ❌    | प्राकृतिक भाषा-संचालित गतिशील व्यावसायिक विस्तार |

### विकास

```bash
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent
npm install
npm run tauri dev      # विकास मोड (Vite HMR + Tauri विंडो)
```

### बिल्ड

```bash
npm run tauri build    # डेस्कटॉप उत्पादन बिल्ड

npm run tauri:android:build   # Android बिल्ड
npm run tauri:ios:build       # iOS बिल्ड
```

डेस्कटॉप बिल्ड आर्टिफ़ैक्ट `src-tauri/target/release/` में हैं।

### परीक्षण

```bash
npm run test           # फ्रंटएंड यूनिट टेस्ट (Vitest watch)

npm run test:e2e       # E2E टेस्ट (Playwright)

# Rust बैकएंड टेस्ट
cd src-tauri && cargo nextest run
cd src-tauri && cargo test

# प्रकार जाँच और लिंटिंग
npm run typecheck
cd src-tauri && cargo clippy -- -D warnings
npm run format         # dprint फ़ॉर्मेटिंग
npm run lint:eslint    # ESLint जाँच
npm run contracts      # API अनुबंध जाँच

# पूर्ण CI जाँच
npm run ci:check
```

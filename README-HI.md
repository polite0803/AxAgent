## AxAgent क्या है?

**AxAgent v2.0** एक पूर्ण-विशेषता क्रॉस-प्लेटफ़ॉर्म AI डेस्कटॉप/मोबाइल एप्लिकेशन है, जो उन्नत AI एजेंट क्षमताओं और समृद्ध विकास उपकरणों को एकीकृत करता है। यह कई मॉडल प्रदाताओं, स्वायत्त पाइपलाइन निष्पादन, विज़ुअल वर्कफ़्लो ऑर्केस्ट्रेशन, स्थानीय ज्ञान प्रबंधन, अंतर्निहित API गेटवे का समर्थन करता है, **Windows / macOS / Linux / Android / iOS** पाँच प्लेटफ़ॉर्मों को कवर करता है।

## मुख्य विशेषताएँ

### 🤖 AI मॉडल समर्थन

- **मल्टी-प्रदाता समर्थन** — OpenAI, Anthropic Claude, Google Gemini, Ollama, OpenClaw, Hermes और सभी OpenAI-संगत API का नेटिव एकीकरण
- **मल्टी-की रोटेशन** — प्रति प्रदाता कई API कुंजियाँ कॉन्फ़िगर करें, दर सीमा दबाव वितरण के लिए स्वचालित रोटेशन
- **स्थानीय मॉडल समर्थन** — Ollama स्थानीय मॉडलों का पूर्ण समर्थन, GGUF/GGML फ़ाइल प्रबंधन सहित
- **Candle अनुमान इंजन** — अंतर्निहित Candle स्थानीय अनुमान, rerank/judge इंटरफ़ेस समर्थन, ऑन-डिमांड GGUF डाउनलोड
- **मॉडल प्रबंधन** — दूरस्थ मॉडल सूचियाँ प्राप्त करना, पैरामीटर अनुकूलन (तापमान, अधिकतम टोकन, top-p आदि)
- **स्ट्रीमिंग आउटपुट** — टोकन-दर-टोकन वास्तविक समय रेंडरिंग, संक्षिप्त करने योग्य विचार ब्लॉक (Claude Extended Thinking)
- **मल्टी-मॉडल तुलना** — कई मॉडलों को एक साथ पूछें, साइड-बाय-साइड तुलना
- **फ़ंक्शन कॉल** — सभी समर्थित प्रदाताओं पर संरचित फ़ंक्शन कॉल
- **OpenAI Responses API** — OpenAI Responses प्रारूप परिवहन समर्थन
- **Realtime API** — OpenAI Realtime API-संगत WebSocket इवेंट पुश

### 🔐 AI एजेंट प्रणाली

एजेंट प्रणाली निम्नलिखित विशेषताओं वाले परिष्कृत आर्किटेक्चर पर बनाई गई है:

- **ReAct तर्क इंजन** — तर्क और कार्रवाई का विलय, विश्वसनीय कार्य निष्पादन के लिए अंतर्निहित स्व-सत्यापन
- **पदानुक्रमित योजनाकार** — चरणों और निर्भरताओं के साथ जटिल कार्यों को संरचित योजनाओं में विघटित करना
- **कार्य विघटनकर्ता** — जटिल कार्यों को निष्पादनीय उप-कार्यों में स्वचालित विघटन
- **गहन शोध** — बहु-स्रोत खोज ऑर्केस्ट्रेशन, उद्धरण ट्रैकिंग और विश्वसनीयता मूल्यांकन
- **तथ्य सत्यापन** — AI-संचालित तथ्य जाँच और स्रोत वर्गीकरण
- **खोज ऑर्केस्ट्रेशन** — कई खोज प्रदाताओं का समन्वय, योजना और परिणाम संश्लेषण
- **शैक्षणिक खोज** — शैक्षणिक साहित्य खोज और उद्धरण विश्लेषण
- **कंप्यूटर नियंत्रण** — AI-नियंत्रित माउस क्लिक, कीबोर्ड इनपुट, स्क्रीन स्क्रॉलिंग, विज़ुअल मॉडल विश्लेषण के साथ
- **स्क्रीन अवधारण** — UI तत्व पहचान के लिए स्क्रीनशॉट कैप्चर और विज़ुअल मॉडल विश्लेषण
- **तीन स्तर की अनुमतियाँ** — डिफ़ॉल्ट (अनुमोदन आवश्यक), संपादन स्वीकार करें (स्वतः अनुमोदन), पूर्ण पहुँच (कोई प्रॉम्प्ट नहीं)
- **सैंडबॉक्स अलगाव** — एजेंट संचालन निर्दिष्ट कार्य निर्देशिका तक सख्ती से सीमित
- **उपकरण अनुमोदन पैनल** — व्यक्तिगत अनुमोदन के साथ उपकरण कॉल अनुरोधों का वास्तविक समय प्रदर्शन
- **लागत ट्रैकिंग** — सत्र द्वारा टोकन उपयोग और लागत सांख्यिकी का वास्तविक समय प्रदर्शन
- **रोकें/फिर से शुरू करें** — किसी भी समय एजेंट निष्पादन निलंबित करें और बाद में फिर से शुरू करें
- **चेकपॉइंट प्रणाली** — विफलता पुनर्प्राप्ति और सत्र पुनः कनेक्ट के लिए स्थायी चेकपॉइंट
- **त्रुटि पुनर्प्राप्ति इंजन** — स्वचालित त्रुटि वर्गीकरण, मूल कारण विश्लेषण और पुनर्प्राप्ति रणनीति निष्पादन
- **लूप का पता लगाना** — एजेंट तर्क में लूपिंग व्यवहार की स्वचालित पहचान और बाधा
- **विचार श्रृंखला** — एजेंट निर्णय लेने की प्रक्रिया का विज़ुअलाइज़ेशन, चरण-दर-चरण विघटन
- **सक्रिय मोड** — एजेंट सक्रिय रूप से सुझाव दे सकता है और कार्रवाई कर सकता है
- **उद्देश्य प्रबंधन** — एजेंट निष्पादन उद्देश्यों और संदर्भ का रखरखाव और ट्रैकिंग

### 👥 मल्टी-एजेंट सहयोग

- **उप-एजेंट समन्वय** — कई सहयोगी एजेंटों के समर्थन के साथ मास्टर-स्लेव आर्किटेक्चर
- **समानांतर निष्पादन** — निर्भरता-जागरूक शेड्यूलिंग के साथ कई एजेंटों द्वारा समानांतर प्रसंस्करण
- **विरोधात्मक बहस** — तर्क शक्ति स्कोरिंग और खंडन ट्रैकिंग के साथ पक्ष/विपक्ष बहस दौर
- **एजेंट भूमिकाएँ** — टीम सहयोग के लिए पूर्वनिर्धारित भूमिकाएँ (शोधकर्ता, योजनाकार, डेवलपर, समीक्षक, संश्लेषक)
- **एजेंट ऑर्केस्ट्रेटर** — मल्टी-एजेंट टीमों के लिए केंद्रीकृत संदेश रूटिंग और स्थिति प्रबंधन
- **संचार ग्राफ़** — एजेंटों के बीच इंटरैक्शन और संदेश प्रवाह का विज़ुअलाइज़ेशन
- **Swarm क्लस्टर** — अनुमति सिंक्रनाइज़ेशन और स्वचालित पुनः कनेक्ट के साथ बहु-प्रक्रिया एजेंट क्लस्टर
- **Buddy प्रणाली** — प्रजाति और विशेषता परिभाषा के साथ विन्यास योग्य साथी एजेंट
- **साझा मेमोरी** — सांख्यिकी और क्वेरी के साथ एजेंटों के बीच साझा मेमोरी स्थान
- **टीम Cron** — टीम स्तर पर Cron कार्य शेड्यूलिंग

### ⭐ कौशल प्रणाली

- **कौशल मार्केटप्लेस** — समुदाय-योगदान कौशल ब्राउज़ करने और इंस्टॉल करने के लिए अंतर्निहित मार्केटप्लेस
- **कौशल निर्माण** — प्रस्तावों से स्वचालित कौशल निर्माण, Markdown संपादक के साथ
- **कौशल विकास** — निष्पादन प्रतिक्रिया के आधार पर AI-संचालित मौजूदा कौशल का स्वचालित विश्लेषण और सुधार
- **कौशल मिलान** — सिमेंटिक मिलान, बातचीत संदर्भ के लिए प्रासंगिक कौशल की सिफारिश
- **कौशल विघटन** — जटिल कार्यों को निष्पादनीय परमाणु कौशल में स्वचालित विघटन (LLM-सहायत/मल्टी-राउंड/वर्कफ़्लो सत्यापन)
- **जनित उपकरण** — एजेंट क्षमताओं का विस्तार करने के लिए AI-संचालित स्वचालित नए उपकरणों का जनरेशन और पंजीकरण
- **कौशल हब** — कौशल खोज और कॉन्फ़िगरेशन प्रबंधन के लिए केंद्रीकृत इंटरफ़ेस
- **कौशल हब क्लाइंट** — सामुदायिक साझाकरण के साथ दूरस्थ कौशल हब एकीकरण
- **कौशल निर्भरता सत्यापन** — कौशल निर्भरताओं और उपकरण उपलब्धता की स्वचालित पहचान
- **कौशल सैंडबॉक्स कंटेनर** — पृथक वातावरण में कौशल का सुरक्षित निष्पादन

### 🔄 वर्कफ़्लो प्रणाली

वर्कफ़्लो इंजन DAG-आधारित कार्य ऑर्केस्ट्रेशन प्रणाली लागू करता है:

- **विज़ुअल वर्कफ़्लो संपादक** — नोड कनेक्शन और कॉन्फ़िगरेशन के साथ ड्रैग-एंड-ड्रॉप वर्कफ़्लो डिज़ाइनर
- **समृद्ध नोड प्रकार** — 15 नोड प्रकार: ट्रिगर, एजेंट, LLM, स्थिति, समानांतर, लूप, मर्ज, विलंब, उपकरण, कोड, सब-वर्कफ़्लो, वेक्टर खोज, दस्तावेज़ विश्लेषण, सत्यापन, अंत
- **वर्कफ़्लो टेम्पलेट** — अंतर्निहित प्रीसेट: कोड समीक्षा, बग सुधार, दस्तावेज़ीकरण, परीक्षण, रिफैक्टरिंग, अन्वेषण, प्रदर्शन, सुरक्षा, सुविधा विकास
- **DAG निष्पादन** — Kahn एल्गोरिथम द्वारा टोपोलॉजिकल सॉर्टिंग, चक्र पहचान के साथ
- **समानांतर शेड्यूलिंग** — पाइपलाइन निष्पादन, तेज़ चरण धीमे चरणों की प्रतीक्षा नहीं करते
- **पुनः प्रयास रणनीति** — घातीय बैकऑफ़, प्रति चरण कॉन्फ़िगर करने योग्य अधिकतम पुनः प्रयास
- **आंशिक पूर्णता** — विफल चरण स्वतंत्र डाउनस्ट्रीम चरणों को अवरुद्ध नहीं करते
- **संस्करण प्रबंधन** — रोलबैक के साथ वर्कफ़्लो टेम्पलेट संस्करण नियंत्रण
- **निष्पादन इतिहास** — स्थिति ट्रैकिंग और डीबगिंग के साथ विस्तृत रिकॉर्ड
- **AI सहायता** — AI-सहायित वर्कफ़्लो डिज़ाइन, नोड सिफारिश और एजेंट प्रॉम्प्ट अनुकूलन
- **सिमेंटिक सत्यापन** — वर्कफ़्लो का सिमेंटिक वैलिडेशन, संभावित समस्याओं का पता लगाना
- **n8n आयात** — n8n निर्देशिका से वर्कफ़्लो आयात समर्थन
- **डीबग पैनल** — वर्कफ़्लो निष्पादन के दौरान वास्तविक समय डीबगिंग और स्थिति विज़ुअलाइज़ेशन

### 📚 ज्ञान और मेमोरी

- **ज्ञान आधार (RAG)** — बहु-ज्ञान आधार समर्थन, दस्तावेज़ अपलोड, स्वचालित पार्सिंग, चंकिंग और वेक्टर इंडेक्सिंग
- **हाइब्रिड खोज** — वेक्टर समानता खोज और पूर्ण-पाठ BM25 रैंकिंग का संयोजन
- **पुनः रैंकिंग** — पुनर्प्राप्ति सटीकता में सुधार के लिए क्रॉस-एनकोडर पुनः रैंकिंग
- **तीन-स्तरीय रिकॉल पाइपलाइन** — AST इंडेक्स + वेक्टर खोज + FTS5 के साथ बहु-स्तरीय रिकॉल तंत्र
- **ज्ञान ग्राफ़** — एंटिटी-ज्ञान संबंध विज़ुअलाइज़ेशन (एंटिटी, विशेषताएँ, संबंध, प्रवाह, इंटरफ़ेस)
- **Wiki प्रणाली** — LLM Wiki संकलक और सत्यापनकर्ता, ज्ञान ग्राफ़ विज़ुअलाइज़ेशन और वृद्धिशील सिंक के साथ
- **Wiki नोट्स** — द्वि-दिशात्मक लिंक, ग्राफ़ दृश्य और स्वचालित लिंक सिंक के साथ नोट प्रणाली

### 🛡️ प्रॉम्प्ट इंजेक्शन सुरक्षा (Prompt-Guard)

- **चार-स्तरीय सुरक्षा प्रणाली** — L1 पैटर्न पहचान (उच्च-जोखिम अवरोधन + मध्यम-जोखिम मार्किंग) → L2 सीमांकक एस्केपिंग → L3 XML रैपर → L4 विश्वास टैग
- **Pipeline ऑर्केस्ट्रेटर** — सीरियल बहु-स्तरीय पहचान पाइपलाइन, अनुकूलन योग्य जोखिम थ्रेसहोल्ड समर्थन
- **Token Smuggling पहचान** — एन्कोडिंग ओबफ़स्केशन और टोकन तस्करी हमलों के खिलाफ विशेष पहचान
- **Strict मोड** — सख्त मोड परीक्षण + मध्यम-जोखिम कारणों का नामकरण + कस्टम मोड दस्तावेज़ीकरण
- **पूर्ण पाइपलाइन एकीकरण** — session / prompt / git / RAG में एकीकृत

- **अनुकूली लेआउट** — तीन-स्तरीय स्वचालित अनुकूलन: डेस्कटॉप/टैबलेट/फ़ोन
- **मोबाइल नेविगेशन** — स्लाइडिंग Drawer नेविगेशन + निचला नेविगेशन बार + फ़्लैश फ़्लोटिंग बटन
- **सुरक्षित क्षेत्र अनुकूलन** — Android सिस्टम स्टेटस बार/नेविगेशन बार के लिए CSS env() अनुकूलन
- **CSP अनुकूलन** — Android WebView के लिए CSP प्रोटोकॉल व्हाइटलिस्ट

### macOS: "ऐप़ क्षतिग्रस्त है" या "डेवलपर को सत्यापित नहीं किया जा सकता"

चूँकि ऐप़ Apple द्वारा हस्ताक्षरित नहीं है:

**1. "किसी भी स्रोत" से ऐप्स की अनुमति दें**
```bash
sudo spctl --master-disable
```

फिर **सिस्टम सेटिंग्स → गोपनीयता और सुरक्षा → सुरक्षा** पर जाएँ और **किसी भी स्रोत** चुनें।

**2. क्वारंटाइन विशेषता हटाएँ**
```bash
sudo xattr -dr com.apple.quarantine /Applications/AxAgent.app
```

**3. macOS Ventura+ के लिए अतिरिक्त चरण**
**सिस्टम सेटिंग्स → गोपनीयता और सुरक्षा** पर जाएँ और **फिर भी खोलें** पर क्लिक करें।

**AxAgent** — это кроссплатформенный десктопный клиент AI-ассистента на базе Tauri 2 (Windows / macOS / Linux / Android / iOS). Он объединяет движок агентов ReAct, визуальную оркестрацию рабочих процессов, локальные RAG-базы знаний, расширения протокола MCP, унифицированный мульти-модельный шлюз, автоматизацию браузера и управление компьютером — выступая в роли AI-рабочей станции для повседневной разработки, исследований, управления знаниями и автоматизации.

## Позиционирование проекта

AxAgent решает три ключевые проблемы:

1. **Унифицированный доступ к мульти-моделям и интеллектуальная маршрутизация** — Используйте OpenAI, Anthropic Claude, Google Gemini, локальные модели Ollama и любые OpenAI-совместимые API в одном интерфейсе, с многоключевой ротацией по квотам, интеллектуальной маршрутизацией по типу задач и сравнением в потоковом режиме
2. **Замкнутый цикл AI от разговора к исполнению** — 47+ встроенных инструментов + визуальные рабочие процессы + расширения MCP + управление браузером/компьютером, AI может манипулировать файлами, выполнять код, управлять Git и планировать задачи
3. **Локальный суверенитет данных** — Разговоры, базы знаний, память и конфигурации хранятся в локальной базе SQLite, API-ключи шифруются AES-256-GCM. Основные функции работают без сторонних облачных сервисов

## Основные возможности

### Мульти-модельный движок

- **9 адаптеров провайдеров**: OpenAI (Chat Completions + Responses + Realtime), Anthropic Claude, Google Gemini, Ollama (с управлением локальными моделями GGUF), OpenClaw, Hermes и любые OpenAI-совместимые API
- **Многоключевая ротация**: Несколько API-ключей на провайдера, автоматическая ротация по квотам, автоматическое переключение при ограничении одного ключа
- **Интеллектуальная маршрутизация**: Автоматический выбор модели по типу задачи (ревью кода / резюмирование / перевод / общее), с настраиваемыми правилами
- **Мониторинг здоровья провайдеров**: Отслеживание успешности, задержки и доступности в реальном времени, с многоуровневой автоматической деградацией
- **Генерация изображений AI**: DALL-E 3 и Flux (Replicate) с предустановками разных размеров
- **Голос в реальном времени**: Голосовой разговор через WebSocket на базе OpenAI Realtime API, с поддержкой прерывания и потоковой транскрипции

### Система агентов (движок ReAct)

- **Иерархический планировщик** (`hierarchical_planner`): Декомпозиция сложных задач в структурированные планы Фаза → Задача, компилируемые в топологическое исполнение DAG
- **Глубокое исследование** (`deep_research`): Оркестрация мульти-источникового поиска с планированием, выполнением, синтезом контента и отслеживанием цитирования
- **Проверка фактов** (`fact_checker`): AI-управляемая проверка фактов с классификатором источников и оценкой достоверности
- **Дерево мыслей** (`tree_of_thoughts`): Многопутевое исследование рассуждений с оценкой ветвей и возвратом
- **Рефлектор** (`reflector`): Самооценка после выполнения и предложения по улучшению
- **Самоверификатор** (`self_verifier`): Автоматическая проверка результатов рассуждений с обнаружением циклов
- **Восстановление после ошибок** (`error_recovery_engine`): Классификация типа ошибки → выбор стратегии → автоматический повтор или корректировка плана, с экспоненциальной задержкой
- **A/B тестирование** (`ab_testing`): Сравнительная оценка различных стратегий рассуждений
- **Система оценки** (`evaluator`): Встроенный фреймворк бенчмарков
- **LoRA дообучение** (`fine_tune`): Встроенный пайплайн обучения с управлением LoRA-адаптерами
- **RL оптимизатор** (`rl_optimizer`): Обучение с подкреплением на основе обратной связи от опыта

**Мульти-агентное сотрудничество**:

- Архитектура координации мастер-подчинённый с параллельным выполнением подагентов и планированием с учётом зависимостей
- Общая доска для обмена информацией между агентами
- Режим состязательных дебатов (раунды За/Против с оценкой силы аргументов)
- Режим Swarm для кластеров многопроцессных агентов
- Проактивный режим: агенты могут инициировать предложения и операции

**Управление компьютером**: AI-управляемые клики мыши, ввод с клавиатуры, прокрутка экрана, с тремя уровнями разрешений (по умолчанию / принимать правки / полный доступ) и изоляцией путей песочницы

**Автоматизация браузера**: Управление браузером через протокол CDP, с навигацией, скриншотами, кликами, заполнением форм и извлечением текста

### Система навыков

- **Маркетплейс навыков**: Просмотр и установка навыков сообщества
- **AI-ассистированное создание**: Автоматическая генерация структур навыков из предложений на естественном языке (`skill:create`)
- **Эволюция навыков** (`evolution_engine`): Автоматический анализ и улучшение навыков на основе обратной связи выполнения
- **Семантическое сопоставление**: Контекстно-зависимая семантическая рекомендация навыков
- **Декомпозиция навыков** (`skill_decomposition`): Автоматическая декомпозиция сложных задач в атомарные комбинации навыков
- **Генерируемые инструменты**: Новые инструменты, генерируемые и регистрируемые AI
- **Исполнение в песочнице**: Навыки выполняются в изолированных средах-песочницах

### Управление знаниями

- **Мульти-RAG базы знаний**: Загрузка документов → автоматический разбор (PDF/DOCX/XLSX/PPTX/TXT) → сегментация → векторная индексация

### API шлюз

Встроенный HTTP + WebSocket шлюз на базе `axum`:

- **Совместимые эндпоинты**: OpenAI `/v1/chat/completions`, API Claude Messages, API Gemini, а также OpenAI Responses и Realtime WebSocket
- **Управление ключами**: Генерация, отзыв, активация/деактивация ключей доступа с поддержкой срока действия

- **SSL/TLS**: Встроенные самоподписанные сертификаты (`rcgen`), поддержка пользовательских сертификатов
- **Внешняя привязка**: Интеграция в один клик с Claude CLI, OpenCode и другими внешними инструментами, автоматическая синхронизация API-ключей

### Бэкенд архитектура: Harness Dependency Injection

Архитектура Rust workspace с **32 крейтами**, следующая паттерну **Harness DI**:

> Все крейты развязаны через трейт-интерфейсы, определённые в axagent-harness, и axagent-runtime собирает и внедряет зависимости во время выполнения.
> Направление зависимостей: `конкретные реализации → harness ← вызывающие`

**harness** является архитектурным краеугольным камнем — ноль бизнес-логики, ноль конкретных реализаций, содержит только определения трейтов, чистые DTO данных, константы и унифицированные типы ошибок. От него зависят все остальные крейты, и он сам не зависит ни от одного axagent-* крейта (200+ определений трейтов, охватывающих Agent/Provider/Tool/RAG/Хранилище/MCP/Плагины/Безопасность/Наблюдаемость/Память/Обучение/Браузер/Мессенджеры и др.).

```
src-tauri/crates/
├── harness/          # Архитектурный краеугольный камень — трейт-интерфейсы, DTO, типы ошибок, DI контракты
├── entities/         # Модели сущностей SeaORM
├── dao/              # Слой доступа к данным (CRUD)
```

## Быстрый старт

### Предварительные требования

- [Node.js](https://nodejs.org/) 20+
- [Rust](https://www.rust-lang.org/) 1.75+ (edition 2024)
- [npm](https://www.npmjs.com/) 10+
- Windows: [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (MSVC + Windows SDK)
- macOS: Xcode Command Line Tools
- Linux: `build-essential` + `libwebkit2gtk-4.1-dev` + `libssl-dev`

### Разработка

```bash
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent
npm install
npm run tauri dev      # Режим разработки (Vite HMR + окно Tauri)
```

### Сборка

```bash
npm run tauri build    # Сборка десктопной версии

npm run tauri:android:build   # Сборка Android
npm run tauri:ios:build       # Сборка iOS
```

Артефакты десктопной сборки находятся в `src-tauri/target/release/`.

### Тестирование

```bash
npm run test           # Модульные тесты фронтенда (Vitest watch)
npm run test:run       # Модульные тесты фронтенда (однократный запуск)
npm run test:e2e       # E2E тесты (Playwright)

# Тесты бэкенда Rust
cd src-tauri && cargo nextest run
cd src-tauri && cargo test

# Проверка типов и линтинг
npm run typecheck
cd src-tauri && cargo clippy -- -D warnings
npm run format         # Форматирование dprint
npm run lint:eslint    # Проверка ESLint
npm run contracts      # Проверка API контрактов

# Полная CI проверка
npm run ci:check
```

### Скрипты

| Команда                  | Назначение                     |
| ------------------------ | ------------------------------ |
| `npm run bump`           | Интерактивное повышение версии |
| `npm run docs`           | Генерация документации TypeDoc |
| `npm run skill:create`   | Создание нового шаблона навыка |
| `npm run skill:validate` | Валидация определения навыка   |
| `npm run check:types`    | Проверка согласованности типов |

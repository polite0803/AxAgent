**AxAgent** — это кроссплатформенный AI-клиент для рабочего стола на базе Tauri 2 (Windows / macOS / Linux / Android / iOS), позиционируемый как рабочая станция на основе ИИ для повседневной разработки, исследований, управления знаниями и автоматизации. Он включает встроенный движок агентов ReAct, когнитивную маршрутизацию (трёхуровневая иерархическая маршрутизация + маршрутизация с дополнением поиска RAR), визуальную оркестрацию рабочих процессов, локальную базу знаний RAG, расширение по протоколу MCP, унифицированный шлюз для нескольких моделей, автоматизацию браузера и управление компьютером — позволяя ИИ перейти от «диалога» к «выполнению».

## Позиционирование проекта

AxAgent решает три ключевые проблемы:

1. **Унифицированное подключение и интеллектуальное планирование нескольких моделей** — единый интерфейс для одновременного использования OpenAI, Anthropic Claude, Google Gemini, DeepSeek, Qwen, GLM, Kimi, Wenxin, локальных моделей Ollama и любых API, совместимых с OpenAI; поддержка автоматической ротации нескольких ключей по квотам, интеллектуальной маршрутизации по типу задачи и потокового сравнения
2. **Замкнутый цикл ИИ от диалога к выполнению** — 163+ встроенных инструмента + визуальные рабочие процессы + расширение MCP + управление браузером/компьютером; ИИ может работать с файлами, запускать код, управлять Git и планировать задачи
3. **Локальный приоритет и суверенитет данных** — журналы диалогов, база знаний, память и конфигурация хранятся в локальной базе данных SQLite; ключи API шифруются с помощью AES-256-GCM; для работы основных функций не требуется сторонний облачный сервис

## Ключевые возможности

### Система когнитивной маршрутизации (Cognitive Router)

AxAgent использует `cognitive_query` как единую точку входа для всех диалогов, сопоставляя намерения пользователя с конкретными возможностями через **трёхуровневую иерархическую маршрутизацию**:

- **L1 Маршрутизация по доменам** (`domain_router`): правила + запасной вариант на LLM; распознаёт 9 основных бизнес-доменов (анализ данных / создание контента / коммуникация / эксплуатация / AI-медиа / финансы / автоматизация / общий и др.)
- **L2 Маршрутизация по кластерам** (`cluster_router`): определяет кластеры возможностей внутри домена (27 кластеров, покрывающих 8 основных бизнес-доменов)
- **L3 Маршрутизация по возможностям**: **маршрутизация с дополнением поиска (RAR)** — из векторной базы возможностей извлекаются Top-K похожих рабочих процессов и внедряются в Prompt; в сочетании с поиском пути по DAG-графу рабочего процесса выдаётся адрес пути (например, `/finance/stock_analysis/tech`) и режим выполнения
- **Режимы выполнения**: `Ask / Plan / Act / Workflow / Direct / Delegate / ParameterExtract / Clarify`, выбираются автоматически по уровню уверенности
- **Система возможностей**: единый реестр (`CapabilityRegistry`) + векторный индекс (`CapabilityIndexer`) + гибридный поиск (`CapabilityRetriever`, векторный + BM25 + жёсткое сопоставление по тегам + исключение негативных примеров)
- **Изоляция системных возможностей**: когнитивный оркестратор и бизнес-рабочие процессы физически изолированы; системные возможности помечены видимостью `SYSTEM_ONLY`; на уровне маршрутизации встроен предохранитель от самоссылок для предотвращения парадокса самореференции
- **Трёхуровневая маршрутизация реализована через DAG рабочих процессов**: 4 предустановленных шаблона маршрутизирующих рабочих процессов (главная оркестрация ~20 узлов + подмаршрутизация L1/L2/L3), выполняемых движком `rt-workflow`

### Мультимодельный движок

- **13 адаптеров провайдеров**: OpenAI (Chat Completions + Responses + Realtime), Anthropic Claude, Google Gemini, DeepSeek, Qwen, GLM, Kimi, Wenxin Yiyan, Ollama, Llama.cpp (локальные модели GGUF), OpenClaw, Hermes, а также все API, совместимые с OpenAI
- **Ротация нескольких ключей**: несколько API-ключей одного провайдера с автоматической ротацией по квотам; автоматическое переключение при ограничении скорости одного ключа
- **Интеллектуальная маршрутизация**: автоматический выбор оптимальной модели по типу задачи (проверка кода / резюмирование / перевод / общий), поддержка пользовательских правил
- **Мониторинг здоровья провайдеров**: отслеживание в реальном времени уровня успеха, задержки и доступности; поддержка многоуровневого автоматического понижения
- **Генерация изображений ИИ**: DALL-E 3 и Flux с несколькими предустановленными размерами
- **Голос в реальном времени**: голосовой диалог через WebSocket на основе OpenAI Realtime API с поддержкой прерывания и потоковой транскрипции

### Система агентов (движок ReAct)

- **Иерархический планировщик** (`hierarchical_planner`): разбивает сложные задачи на структурированный план Phase → Task, компилируемый в топологическое выполнение DAG
- **Глубокое исследование** (`deep_research`): оркестрация поиска по нескольким источникам, включая план поиска, выполнение поиска, синтез контента и отслеживание цитирований
- **Проверка фактов** (`fact_checker`): проверка фактов на основе ИИ, включая классификатор источников и оценку достоверности
- **Дерево мыслей** (`tree_of_thoughts`): исследование рассуждений по нескольким путям, оценка ветвей и возврат
- **Рефлектор** (`reflector`): самооценка и предложения по улучшению после выполнения задачи
- **Самопроверка** (`self_verifier`): автоматическая проверка результатов рассуждений, включая обнаружение циклов
- **Восстановление после ошибок** (`error_recovery_engine`): классификация типов ошибок → выбор стратегии восстановления → автоматический повтор или корректировка плана, поддержка экспоненциальной задержки
- **A/B-тестирование** (`ab_testing`): сравнительная оценка различных стратегий рассуждений
- **Система оценки** (`evaluator`): встроенная платформа бенчмарков
- **Тонкая настройка LoRA** (`fine_tune`): встроенный конвейер обучения с поддержкой управления адаптерами LoRA
- **Оптимизатор RL** (`rl_optimizer`): усиленное обучение политики на основе эмпирической обратной связи

**Многоагентное взаимодействие**:

- Архитектура координации «ведущий-ведомый», параллельное выполнение субагентов, планирование с учётом зависимостей
- Общая доска (blackboard) для обмена информацией между агентами
- Режим состязательных дебатов (раунды «За/Против» с оценкой силы аргументов)
- Кластерный режим Swarm, кластер агентов из нескольких процессов
- Проактивный режим: агенты могут самостоятельно инициировать предложения и действия

**Управление компьютером**: управляемые ИИ клики мышью, ввод с клавиатуры, прокрутка экрана; три уровня разрешений (по умолчанию / разрешено редактирование / полный доступ); изоляция путей через песочницу

**Автоматизация браузера**: управление браузером через протокол CDP с поддержкой навигации, скриншотов, кликов, заполнения форм и извлечения текста

### Система навыков

- **Магазин навыков**: просмотр и установка навыков сообщества
- **Создание с помощью ИИ**: автоматическое создание структуры навыка из предложения на естественном языке (`skill:create`)
- **Эволюция навыков** (`evolution_engine`): автоматический анализ и улучшение навыков на основе обратной связи от выполнения
- **Семантическое сопоставление**: автоматическая рекомендация релевантных навыков по семантике контекста диалога
- **Декомпозиция навыков** (`skill_decomposition`): автоматическое разбиение сложных задач на комбинации атомарных навыков
- **Генерация инструментов**: ИИ генерирует и регистрирует новые инструменты
- **Выполнение в песочнице**: безопасное выполнение навыков в изолированной песочнице

- **Выполнение с топологической сортировкой Кана**: автоматическое обнаружение циклических зависимостей, планирование параллельного конвейера
- **Встроенные шаблоны**: проверка кода, исправление ошибок, генерация документации, тестирование, рефакторинг, исследование, анализ производительности, проверка безопасности, разработка функций
- **Сериализация YAML**: импорт и экспорт определений рабочих процессов
- **Управление версиями**: контроль версий шаблонов
- **Проектирование с помощью ИИ**: проектирование рабочих процессов с помощью ИИ, рекомендации узлов и диагностика

### Управление знаниями

- **RAG с несколькими базами знаний**: загрузка документов → автоматический разбор (PDF/DOCX/XLSX/PPTX/TXT) → разбиение на фрагменты → векторное индексирование
- **Гибридный поиск**: векторное сходство (sqlite-vec + локальные эмбеддинги candle) + полнотекстовый поиск BM25 (FTS5), гибридная сортировка
- **Self-RAG**: автоматическая рефлексия и проверка результатов поиска
- **Переранжирование**: переранжирование результатов с помощью Cross-encoder
- **Граф знаний**: извлечение сущностей → построение связей → визуализация графа
- **Мониторинг файлов**: отслеживание изменений файлов в реальном времени на основе `notify`, автоматическое инкрементальное индексирование
- **LLM Wiki**: компилятор и валидатор Wiki с поддержкой ИИ

### API-шлюз

Встроенный шлюз HTTP + WebSocket на базе `axum`:

- **Совместимые конечные точки**: OpenAI `/v1/chat/completions`, Claude Messages API, Gemini API, а также OpenAI Responses и Realtime WebSocket
- **Управление ключами**: генерация, отзыв, включение/отключение ключей доступа, поддержка срока действия
- **Отслеживание использования**: статистика запросов и потребления токенов по ключу/провайдеру/дате, экспорт метрик Prometheus
- **Ограничение скорости**: алгоритм «ведро токенов» на основе `governor`
- **SSL/TLS**: встроенный самоподписанный сертификат (`rcgen`), поддержка пользовательских сертификатов
- **Внешние подключения**: интеграция внешних инструментов в один клик, таких как Claude CLI, OpenCode, с автоматической синхронизацией API-ключей
- **Билеты реального времени**: временные билеты аутентификации на основе HMAC для безопасной передачи при подключении WebSocket
- **Режим сервера**: опциональный бинарный файл `axagent-server`, предоставляющий возможности настольного приложения как сервис

### Протокол MCP

Полная реализация MCP (Model Context Protocol) на основе `rmcp`:

- **Транспортный уровень**: дочерний процесс stdio + Streamable HTTP + SSE
- **Аутентификация OAuth**: поддержка процесса авторизации OAuth для серверов MCP
- **Обнаружение инструментов**: автоматическое обнаружение и регистрация инструментов, предоставляемых серверами MCP
- **Менеджер MCP**: управление жизненным циклом серверов, проверка работоспособности, автоматическое переподключение

Совместимая с OpenClaw трёхуровневая архитектура плагинов (встроенные / связанные / внешние):

- Установка через npm-пакеты, встроенный UI магазина для поиска и установки

- Установщик навыков: установка навыков из пакетов плагинов в систему навыков

### Движок динамического UI

- **Управление через Schema**: декларативное построение интерфейсов через JSON Schema без написания кода
- **31 встроенный компонент**: контейнеры (7) / отображение данных (6) / формы (9) / медиа (4) / прочее (5)
- **Привязка данных**: декларативная привязка источников данных и условный рендеринг
- **NL2UI**: генерация динамических UI-интерфейсов непосредственно из естественного языка

### Клиентский SDK ACP

- **ACP (Agent Client Protocol)**: двуязычный SDK (TypeScript + Python), без сторонних зависимостей
- Управление сессиями, отправка Prompt, запись вызовов инструментов, поток событий WebSocket
- Взаимодействие со службой AxAgent через конечные точки `/acp/v1/*`

### Безопасность

- **Шифрование AES-256-GCM**: локальное шифрованное хранение ключей API и конфиденциальной конфигурации (crate `crypto`)
- **Защита от инъекций в промпты**: четырёхуровневый конвейер защиты (`prompt-guard`) — обнаружение паттернов → экранирование разделителей → XML-обёртки → доверительные теги, интегрированный во всю цепочку: сессии, построение промптов, Git, RAG
- **Защита от SSRF**: проверка безопасности URL, блокировка запросов к внутренним адресам
- **Фильтрация контента**: фильтрация безопасности контента нескольких типов
- **Ограничение скорости**: ограничение вызовов инструментов и API-запросов через «ведро токенов»
- **Предохранитель**: автоматический разрыв при последовательных сбоях
- **Контроль доступа**: управление доступом к инструментам на основе политик
- **Изоляция в песочнице**: изоляция среды выполнения агентов и навыков

### Инструменты для разработчиков

### Архитектура бэкенда: паттерн внедрения зависимостей Harness

Используется архитектура Rust workspace, включающая **37 членов** (основной crate + 35 библиотечных crate + schema-gen), следующая **архитектуре внедрения зависимостей Harness**:

> Все crate развязаны через интерфейсы трейтов, определённые в axagent-harness; во время выполнения зависимости собираются и внедряются через axagent-runtime.
> Направление зависимостей: `конкретная реализация → harness ← вызывающая сторона`

**harness** — краеугольный камень архитектуры: ноль бизнес-логики, ноль конкретных реализаций, только определения трейтов, чистые DTO данных, константы и унифицированные типы ошибок. Его используют все остальные crate, при этом сам он не зависит ни от одного crate axagent-* (200+ определений трейтов, охватывающих Agent/Provider/Tool/RAG/хранилище/MCP/плагины/безопасность/наблюдаемость/память/обучение/браузер/сообщения/когнитивную маршрутизацию и др.).


### Разработка

```bash
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent
npm install
npm run tauri dev      # Режим разработки (Vite HMR фронтенда + окно Tauri)
```

### Сборка

```bash
npm run tauri build    # Продакшен-сборка для десктопа

npm run tauri:android:build   # Сборка для Android
npm run tauri:ios:build       # Сборка для iOS
```

Артефакты сборки для десктопа находятся в `src-tauri/target/release/`.

### Тестирование

```bash
npm run test           # Модульные тесты фронтенда (Vitest watch)
npm run test:run       # Модульные тесты фронтенда (однократный запуск)
npm run test:e2e       # E2E-тесты (Playwright)

# Тесты бэкенда Rust
cd src-tauri && cargo test

# Проверка типов и Lint
npm run typecheck
cd src-tauri && cargo clippy -- -D warnings
npm run format         # Форматирование dprint
npm run lint:eslint    # Проверка ESLint
npm run contracts      # Проверка контрактов API

# Полная проверка CI
npm run ci:check
```

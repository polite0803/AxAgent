**AxAgent** — это кроссплатформенный настольный клиент ИИ-ассистента с открытым исходным кодом, поддерживающий **Windows / macOS / Linux / Android / iOS**. Это намного больше, чем интерфейс чата: он объединяет движок агентов ReAct, визуальную оркестрацию рабочих процессов, локальные RAG-базы знаний, расширения протокола MCP, единый мультимодельный шлюз, автоматизацию браузера и управление компьютером, выступая в роли ИИ-рабочей станции для повседневной разработки, исследований, управления знаниями и автоматизации.

## Что решает AxAgent

AxAgent решает три ключевые проблемы:

1. **Единая оркестрация нескольких моделей**: Используйте OpenAI, Anthropic Claude, Google Gemini, локальные модели Ollama и любой совместимый с OpenAI API в одном интерфейсе с ротацией нескольких ключей, интеллектуальной маршрутизацией моделей и потоковым сравнением
2. **Операционализация возможностей ИИ**: Расширение ИИ от «разговора» до «исполнения» — через 47+ встроенных инструментов, визуальные рабочие процессы, расширения MCP, автоматизацию браузера и управление компьютером ИИ может напрямую манипулировать файлами, запускать код, управлять Git и планировать задачи
3. **Локальный приоритет и суверенитет данных**: Беседы ИИ, базы знаний, память и файлы конфигурации хранятся в локальной базе данных SQLite. Ключи API шифруются с помощью AES-256-GCM. Основные функции работают без каких-либо облачных сервисов третьих лиц.

## Основные возможности

### Мультимодельный движок

- **9 адаптеров провайдеров**: OpenAI (Chat Completions + Responses + Realtime), Anthropic Claude, Google Gemini, Ollama (с управлением GGUF), OpenClaw, Hermes, а также все совместимые с OpenAI API
- **Ротация нескольких ключей**: Настройте несколько ключей API для одного провайдера с автоматической ротацией на основе квот для избежания прерываний из-за лимитов скорости
- **Интеллектуальная маршрутизация**: Автоматический выбор наиболее подходящей модели по типу задачи (ревью кода / резюме / перевод / общие), с настраиваемыми правилами маршрутизации
- **Мониторинг состояния провайдеров**: Отслеживание в реальном времени доли успехов, задержки и доступности по каждому провайдеру, с поуровневым автоматическим откатом (ProviderTier)
- **Генерация изображений ИИ**: DALL-E 3 и Flux (Replicate) с предустановками нескольких размеров
- **Голос в реальном времени**: Голосовой чат по WebSocket на базе OpenAI Realtime API с поддержкой прерываний и потоковой транскрипции

### Система агентов

Вся система агентов построена на **движке ReAct (Reasoning + Acting)** и включает следующие реализованные подсистемы:

- **Иерархический планировщик** (`hierarchical_planner`): Разбивает сложные задачи на структурированные планы Phase → Task с зависимостями, компилируемые в топологическое выполнение DAG
- **Глубокое исследование** (`deep_research`): Оркестрация многоисточникового поиска, включая планирование поиска (`search_planner`), выполнение поиска (`search_orchestrator`), синтез контента (`content_synthesizer`) и отслеживание цитат (`citation_tracker`)
- **Проверка фактов** (`fact_checker`): Проверка фактов с помощью ИИ с классификатором источников (`source_classifier`), валидатором источников (`source_validator`) и оценщиком достоверности (`credibility_evaluator`)
- **Дерево мыслей** (`tree_of_thoughts`): Исследование рассуждений по нескольким путям с оценкой ветвей и возвратом
- **Рефлектор** (`reflector`): Самооценка и предложения по улучшению после выполнения задачи
- **Самоверификатор** (`self_verifier`): Автоматическая проверка результатов рассуждений с обнаружением циклов (`cycle_detector`) для предотвращения бесконечных циклов
- **Восстановление после ошибок** (`error_recovery_engine`): Классификация типов ошибок → выбор стратегии восстановления → автоматический повтор или корректировка плана с экспоненциальным откатом
- **A/B-тестирование** (`ab_testing`): Сравнительная оценка различных стратегий рассуждений
- **Система оценки** (`evaluator`): Встроенный фреймворк бенчмарков с поддержкой наборов данных, метрик и генерации отчётов
- **Тонкая настройка LoRA** (`fine_tune`): Встроенный обучающий конвейер с управлением адаптерами LoRA
- **RL-оптимизатор** (`rl_optimizer`): Обучение с подкреплением на основе опыта с experience replay и градиентами политики
- **Рекомендатель инструментов** (`tool_recommender`): Анализ и рекомендации паттернов использования инструментов на основе контекста

**Мультиагентное взаимодействие**:

- Архитектура координации «ведущий-ведомый» (`coordinator`) с параллельным выполнением подагентов и планированием с учётом зависимостей
- Общая доска (`shared_blackboard`) для обмена информацией между агентами
- Режим состязательных дебатов с раундами «за/против» и оценкой силы аргументов
- Режим роя (swarm) с многопроцессными кластерами агентов, поддерживающими синхронизацию прав и автопереподключение
- Проактивный режим (`proactive_mode`): Агенты могут проактивно предлагать рекомендации и действия

**Управление компьютером**: Клики мышью, ввод с клавиатуры, прокрутка экрана, управляемые ИИ, с трёхуровневыми разрешениями (Default / Accept Edits / Full Access) и изоляцией путей в песочнице

**Автоматизация браузера**: Управление браузером через протокол CDP с поддержкой навигации, скриншотов, кликов, заполнения форм, извлечения текста и мониторинга состояния страницы

### Система навыков (Skill System)

- **Маркетплейс навыков**: Просматривайте и устанавливайте навыки сообщества
- **Создание с помощью ИИ**: Автоматическое создание структур навыков из предложений на естественном языке
- **Эволюция навыков** (`evolution_engine`): Автоматический анализ и улучшение навыков на основе обратной связи от выполнения
- **Семантическое сопоставление** (`skill`): Семантическое сопоставление и автоматическая рекомендация релевантных навыков на основе контекста беседы
- **Декомпозиция навыков** (`skill_decomposition`): Автоматическое разбиение сложных задач на комбинации атомарных навыков
- **Сгенерированные инструменты** (`generated_tool`): Новые инструменты, сгенерированные и зарегистрированные ИИ
- **Выполнение в песочнице** (`sandbox`): Навыки безопасно выполняются в изолированных средах песочницы

### Визуальный рабочий процесс

Редактор рабочих процессов DAG с перетаскиванием на базе ReactFlow 12:

- **17 типов узлов**: Trigger, Agent, LLM Call, Conditional Branch, Parallel Fork, Loop, Merge, Delay, Tool Call, Code Execution, Sub-workflow, Vector Retrieval, Document Parsing, Validation, End, Business Rule, Agent Role
- **Выполнение с топологической сортировкой Кана**: Автоматическое обнаружение циклических зависимостей с параллельным планированием конвейера
- **Встроенные шаблоны**: Ревью кода, Исправление багов, Генерация документов, Тестирование, Рефакторинг, Исследование, Анализ производительности, Аудит безопасности, Разработка функций
- **Сериализация YAML**: Определения рабочих процессов поддерживают импорт/экспорт YAML
- **Управление версиями**: Контроль версий шаблонов рабочих процессов
- **Помощь ИИ**: Проектирование рабочих процессов с помощью ИИ и рекомендации по узлам

### Управление знаниями

- **Мульти-KB RAG**: Загрузка документа → автоматический парсинг (PDF/DOCX/XLSX/PPTX/TXT) → фрагментация → векторная индексация
- **Гибридный поиск**: Векторное сходство (sqlite-vec + локальные эмбеддинги candle) + полнотекстовый поиск BM25 (FTS5) с гибридным ранжированием
- **Self-RAG**: Генерация с собственным расширением извлечением, с автоматической рефлексией и верификацией результатов извлечения
- **Переранжирование**: Переранжирование результатов с помощью cross-encoder для повышения точности
- **Граф знаний**: Извлечение сущностей (`EntityExtractor`) → построение отношений → визуальный граф
- **Отслеживание файлов**: Мониторинг изменений файлов в реальном времени через `notify` с автоматической инкрементной индексацией
- **LLM Wiki**: ИИ-компилятор и валидатор Wiki с браузерным расширением для клиппинга Wiki

### Система памяти

- **Память с несколькими пространствами имён**: Изоляция по проекту/теме, поддержка ручного ввода и автоизвлечения ИИ
- **Интеграция персистентности**: Замкнутый цикл памяти с Honcho и Mem0
- **Профиль пользователя** (`user_profile` / `profile`): Автоматическое обучение стилю кодирования (отступы/именование/комментарии), предпочтениям технологического стека и стилю общения
- **Перенос стиля** (`style`): Извлечение признаков стиля кода → применение к коду, сгенерированному ИИ
- **Интеграция Dream** (`dream`): Фоновая автоматическая консолидация фрагментов памяти и паттернов поведения в структурированные знания
- **Память проекта** (`project_memory`): Сохранение контекста для каждого проекта

### API-шлюз

Встроенный сервер HTTP + WebSocket шлюза на базе `axum`:

- **Совместимые эндпоинты**: OpenAI `/v1/chat/completions`, Claude Messages API, Gemini API, а также OpenAI Responses и Realtime WebSocket
- **Управление ключами**: Генерация, отзыв, включение/отключение ключей доступа с поддержкой истечения срока
- **Отслеживание использования**: Счётчики запросов и статистика потребления токенов по ключу, провайдеру и дате с экспортом метрик Prometheus
- **Ограничение скорости**: Алгоритм token bucket через `governor` с настраиваемыми политиками лимитов
- **SSL/TLS**: Встроенные самоподписанные сертификаты (`rcgen`) с поддержкой пользовательских сертификатов
- **Внешняя связь**: Интеграция в один клик с Claude CLI, OpenCode и другими внешними инструментами с автосинхронизацией ключей API
- **Билеты реального времени**: Временные билеты аутентификации на базе HMAC для безопасной передачи соединений WebSocket в реальном времени

### Интеграция с платформами обмена сообщениями

### Протокол MCP

Полная реализация MCP (Model Context Protocol) на базе crate `rmcp`:

- **Транспортный уровень**: Дочерний процесс stdio + Streamable HTTP + WebSocket
- **OAuth-аутентификация**: Поддержка потока авторизации OAuth для серверов MCP
- **Обнаружение инструментов**: Автоматическое обнаружение и регистрация инструментов, предоставляемых серверами MCP
- **Менеджер MCP**: Управление жизненным циклом сервера, проверки состояния, автопереподключение

### Система плагинов

Трёхуровневая архитектура плагинов, совместимая с OpenClaw (Built-in / Bundled / External), поддерживает:

- Установку npm-пакетов со встроенным интерфейсом маркетплейса для поиска и установки
- Определение манифеста плагина, объявления разрешений, изолированное выполнение в песочнице

- Установщик навыков: установка навыков из пакетов плагинов в систему навыков

### Безопасность

- **Шифрование AES-256-GCM**: Локальное зашифрованное хранилище для ключей API и чувствительной конфигурации (crate `crypto`)
- **Защита от инъекции промптов**: Конвейер защиты из четырёх уровней (`prompt-guard`) — обнаружение паттернов → экранирование разделителей → XML-обёртка → метки доверия, интегрированный в сессии, конструирование промптов, Git и RAG по всему конвейеру
- **Защита от SSRF** (`ssrf_guard`): Проверки безопасности URL, блокирующие запросы к внутренним сетевым адресам
- **Фильтрация контента** (`content_filter`): Многофункциональная фильтрация безопасности контента
- **Ограничение скорости** (`rate_limiter`): Ограничение скорости token bucket для вызовов инструментов и API-запросов
- **Предохранитель** (`circuit_breaker`): Автоматическое размыкание цепи при последовательных сбоях для защиты стабильности системы
- **Контроль доступа** (`tool_access`): Управление доступом к инструментам на основе политик
- **Изоляция песочницы**: Изоляция среды выполнения для агентов и навыков

### Опыт разработчика

- **Распределённая трассировка** (`telemetry`): Интеграция с OpenTelemetry с визуализацией Span/Trace

- **Фреймворк бенчмарков**: Бенчмарки Criterion (tool_exec / llm_call / search), оценка SWE-bench и Terminal-bench

### Архитектура бэкенда: паттерн внедрения зависимостей Harness

Бэкенд использует архитектуру Rust workspace с **32 crates**, следуя **паттерну архитектуры Harness**:

```
Все crates развязаны через интерфейсы trait, определённые в axagent-harness.
Среда выполнения (axagent-runtime) собирает и внедряет зависимости во время выполнения.

Направление зависимости: Конкретные реализации → harness ← Вызывающие
```

**harness** — краеугольный камень архитектуры: ноль бизнес-логики, ноль конкретных реализаций, содержит только определения trait, чистые DTO данных, константы и единые типы ошибок. От него зависят все остальные crates, и он не зависит ни от одного другого crate axagent-*.

```
src-tauri/crates/
├── harness/          # Краеугольный камень архитектуры — интерфейсы trait, DTO, единые типы ошибок, DI-контракты
│                     #   200+ определений trait, покрывающих: Agent/Provider/Tool/RAG/Storage/
│                     #   MCP/Plugins/Security/Observability/Memory/Learning/Browser/Messaging
│
├── entities/         # Модели сущностей SeaORM
├── dao/              # Слой доступа к данным (CRUD)
├── migration/        # Миграции базы данных
│
├── crypto/           # Шифрование/расшифровка AES-256-GCM и управление ключами
├── credential/       # Безопасное хранение учётных данных (ключи API и т.д.)
├── storage/          # Абстракция файлового хранилища (Local / S3 / WebDAV), поддержка чтения/записи ZIP
├── cache/            # Универсальный кэширующий слой (в памяти)
├── disk-cache/       # Дисковый файловый кэш
├── search/           # Поисковый движок (FTS5 + sqlite-vec + эмбеддинги candle)
├── document-parser/  # Извлечение текста документов (PDF/DOCX/XLSX/PPTX)
├── kit/              # Набор утилит — помощники пути/кодировки/хэша/даты

├── runtime-core/     # Общие типы среды выполнения, константы конфигурации
├── runtime/          # Оркестрация сервисов среды выполнения — собирает все 30+ crates, DI-контейнер среды выполнения
│                     #   Управляет: сессиями/терминалами/webhooks/лимитами/правами/SSRF/шиной событий/состоянием

│
├── agent/            # Ядро ИИ-агента — 80+ модулей
│                     #   Движок ReAct/иерархическое планирование/глубокое исследование/проверка фактов/дерево мыслей/
│                     #   рефлексия/самоверификация/восстановление ошибок/RL-оптимизация/тонкая настройка LoRA/
│                     #   оценка/рекомендация инструментов/A-B тестирование/координатор/доска/конвейер видения/
│                     #   веб-поиск/академический поиск/компиляция wiki и другое
│
├── orchestrator/     # Оркестрация агентов — мультиагентное планирование, декомпозиция DAG, динамическое выполнение подграфов
├── providers/        # Адаптеры провайдеров моделей — OpenAI/Anthropic/Gemini/Ollama/
│                     #   OpenClaw/Hermes/Генерация изображений (DALL-E/Flux)/Realtime/Responses
├── tools/            # Система инструментов — trait Tool/реестр/оркестрация/потоковая передача/песочница/47+ встроенных инструментов
├── gateway/          # API-шлюз — HTTP/WS сервер axum, OAuth, ограничение скорости, Prometheus
├── mcp/              # Протокол MCP — stdio + Streamable HTTP, на базе rmcp
├── trajectory/       # Система обучения — память/эволюция навыков/профиль пользователя/интеграция dream
├── plugins/          # Система плагинов — совместимая с OpenClaw, установка npm-пакетов, маркетплейс
├── telemetry/        # Наблюдаемость — OpenTelemetry, структурированное логирование, метрики времени выполнения
```

## Быстрый старт

### Требования

- [Node.js](https://nodejs.org/) 20+
- [Rust](https://www.rust-lang.org/) 1.75+, edition 2024
- [npm](https://www.npmjs.com/) 10+
- Windows: [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (MSVC + Windows SDK)
- macOS: Xcode Command Line Tools
- Linux: `build-essential` + `libwebkit2gtk-4.1-dev` + `libssl-dev`

### Сборка

```bash
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent
npm install
npm run tauri dev      # Режим разработки
npm run tauri build    # Продакшн-сборка
```

Артефакты сборки находятся в `src-tauri/target/release/`.

### Тестирование

```bash
npm run test           # Юнит-тесты фронтенда (Vitest watch)
npm run test:run       # Юнит-тесты фронтенда (один прогон)
npm run test:e2e       # E2E-тесты (Playwright)

# Тесты бэкенда Rust
cd src-tauri && cargo nextest run
cd src-tauri && cargo test

# Проверка типов и линтинг
npm run typecheck
cd src-tauri && cargo clippy -- -D warnings
npm run format

# Полная проверка CI
npm run ci:check
```

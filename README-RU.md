## Что такое AxAgent?

**AxAgent v2.0** — это полнофункциональное кроссплатформенное AI-приложение десктоп/мобильное, объединяющее продвинутые возможности AI-агентов и богатые инструменты разработки. Поддерживает нескольких провайдеров моделей, автономное выполнение пайплайнов, визуальную оркестрацию рабочих процессов, локальное управление знаниями, встроенный API-шлюз, охватывая пять платформ **Windows / macOS / Linux / Android / iOS**.

## Основные функции

### 🤖 Поддержка AI-моделей

- **Мультипровайдерная поддержка** — Нативная интеграция OpenAI, Anthropic Claude, Google Gemini, Ollama, OpenClaw, Hermes и всех OpenAI-совместимых API
- **Ротация нескольких ключей** — Настройка нескольких API-ключей на провайдера с автоматической ротацией для распределения нагрузки лимитов
- **Поддержка локальных моделей** — Полная поддержка локальных моделей Ollama, включая управление файлами GGUF/GGML
- **Механизм вывода Candle** — Встроенный локальный вывод Candle, поддержка интерфейсов rerank/judge, загрузка GGUF по требованию
- **Управление моделями** — Получение списков удалённых моделей, настройка параметров (температура, макс. токены, top-p и т.д.)
- **Потоковый вывод** — Рендеринг в реальном времени токен за токеном с сворачиваемыми блоками размышлений (Claude Extended Thinking)
- **Сравнение нескольких моделей** — Одновременный вопрос нескольким моделям с параллельным сравнением
- **Вызовы функций** — Структурированные вызовы функций для всех поддерживаемых провайдеров
- **OpenAI Responses API** — Поддержка транспорта в формате OpenAI Responses
- **Realtime API** — Push-события WebSocket, совместимые с OpenAI Realtime API
- **Генерация изображений AI** — DALL-E 3 и Flux (Replicate), несколько пресетов размеров (1:1/16:9/9:16/4:3), негативные промпты
- **Умная маршрутизация моделей** — Автоматическая маршрутизация по типу задачи (ревью кода/резюмирование/перевод), пользовательские правила маршрутизации
- **Голосовой вызов** — Разговор голосом в реальном времени через OpenAI Realtime API, переключение состояний подключение/говорение/прослушивание

### 🔐 Система AI-агентов

Система агентов построена на сложной архитектуре со следующими характеристиками:

- **Механизм рассуждений ReAct** — Слияние рассуждений и действий со встроенной самопроверкой для надёжного выполнения задач
- **Иерархический планировщик** — Декомпозиция сложных задач в структурированные планы с фазами и зависимостями
- **Декомпозитор задач** — Автоматическая декомпозиция сложных задач в выполнимые подзадачи
- **Глубокое исследование** — Многоисточниковая оркестрация поиска, отслеживание цитирования и оценка достоверности
- **Проверка фактов** — Проверка фактов на базе ИИ и классификация источников
- **Оркестрация поиска** — Координация нескольких поисковых провайдеров с планированием и синтезом результатов
- **Академический поиск** — Поиск академической литературы и анализ цитирования
- **Управление компьютером** — Управляемые ИИ клики мыши, ввод с клавиатуры, прокрутка экрана с анализом визуальной модели
- **Восприятие экрана** — Захват скриншотов и анализ визуальной моделью для идентификации элементов UI
- **Три уровня разрешений** — По умолчанию (требуется одобрение), Принимать изменения (автоодобрение), Полный доступ (без запросов)
- **Изоляция песочницы** — Операции агента строго ограничены указанным рабочим каталогом
- **Панель одобрения инструментов** — Отображение в реальном времени запросов на вызов инструментов с индивидуальным одобрением
- **Отслеживание расходов** — Отображение в реальном времени использования токенов и статистики расходов по сессиям
- **Пауза/Возобновление** — Приостановка выполнения агента в любой момент и возобновление позже
- **Система контрольных точек** — Постоянные контрольные точки для восстановления после сбоев и переподключения сессий
- **Механизм восстановления ошибок** — Автоматическая классификация ошибок, анализ корневых причин и выполнение стратегий восстановления
- **Обнаружение циклов** — Автоматическое обнаружение и прерывание циклического поведения в рассуждениях агента
- **Цепочка мыслей** — Визуализация процесса принятия решений агентом, пошаговая декомпозиция
- **Проактивный режим** — Агент может проактивно предлагать рекомендации и выполнять действия
- **Управление целями** — Поддержание и отслеживание целей выполнения и контекста агента
- **Панель пула агентов** — Визуализация состояния подагента/Worker/шага рабочего процесса в реальном времени
- **Панель рефлексии агента** — Оценка качества после задачи, анализ эффективности, паттерны ошибок, предложения по улучшению
- **Селектор экспертов** — Импорт/экспорт/настройка ролей экспертов, фильтрация по категориям, встроенные пресеты
- **Дерево иерархии агентов** — Визуализация иерархии агентов и топологии сотрудничества
- **Классификатор намерений** — Автоматическая идентификация типа намерения пользовательского ввода
- **Управление состоянием убеждений** — Поддержание состояния понимания контекста агента
- **Оценщик целей** — Оценка выполнения и качества целей задачи
- **Управление окном контекста** — Интеллектуальное управление окном контекста, оптимизация использования токенов
- **Память проекта** — Сохранение знаний на уровне проекта между сессиями
- **Управление базой знаний** — Операции CRUD базы знаний
- **Система заметок** — Структурированное хранение и поиск заметок внутри агентов

### 👥 Мультиагентное сотрудничество

- **Координация подагентов** — Архитектура ведущий-ведомый с поддержкой нескольких коллаборативных агентов
- **Параллельное выполнение** — Параллельная обработка несколькими агентами с учётом зависимостей при планировании
- **Состязательная дискуссия** — Раунды дебатов Про/Контра с оценкой силы аргументов и отслеживанием опровержений
- **Роли агентов** — Предопределённые роли (исследователь, планировщик, разработчик, рецензент, синтезатор) для командной работы
- **Оркестратор агентов** — Централизованная маршрутизация сообщений и управление состоянием для мультиагентных команд
- **Граф коммуникации** — Визуализация взаимодействий и потоков сообщений между агентами
- **Кластер Swarm** — Мультипроцессный кластер агентов с синхронизацией разрешений и автоматическим переподключением
- **Система Buddy** — Настраиваемые агенты-партнёры с определением видов и атрибутов
- **Общая память** — Разделяемое пространство памяти между агентами со статистикой и запросами
- **Командный Cron** — Планирование задач cron на уровне команды
- **Панель сотрудничества** — Управление сессиями сотрудничества в реальном времени, обмен кодом приглашения, роли участников (Владелец/Редактор/Читатель)
- **Обмен сессией** — Ссылка для обмена в один клик, настройка прав доступа к терминалу/файлам/модели

### ⭐ Система навыков

- **Маркетплейс навыков** — Встроенный маркетплейс для просмотра и установки навыков от сообщества
- **Создание навыков** — Автоматическое создание навыков из предложений с Markdown-редактором
- **Эволюция навыков** — Управляемый ИИ автоматический анализ и улучшение существующих навыков на основе обратной связи от выполнения
- **Панель эволюции навыков** — Визуализация поколения эволюции, лучшей/средней пригодности, состояния сходимости
- **Сопоставление навыков** — Семантическое сопоставление, рекомендация релевантных навыков к контексту разговора
- **Декомпозиция навыков** — Автоматическая декомпозиция сложных задач в выполнимые атомарные навыки (LLM-ассистирование/мультираунд/валидация рабочим процессом)
- **Сгенерированные инструменты** — Управляемая ИИ автоматическая генерация и регистрация новых инструментов для расширения возможностей агента
- **Хаб навыков** — Централизованный интерфейс обнаружения и управления конфигурацией навыков
- **Клиент хаба навыков** — Интеграция с удалённым хабом навыков с совместным использованием сообществом
- **Проверка зависимостей навыков** — Автоматическое обнаружение зависимостей навыков и доступности инструментов
- **Контейнер песочницы навыков** — Безопасное выполнение навыков в изолированной среде

### 🔄 Система рабочих процессов

Механизм рабочих процессов реализует систему оркестрации задач на основе DAG:

- **Визуальный редактор рабочих процессов** — Конструктор рабочих процессов с перетаскиванием с подключением и настройкой узлов
- **Богатые типы узлов** — 15 типов узлов: триггер, агент, LLM, условие, параллельный, цикл, слияние, задержка, инструмент, код, подпроцесс, векторный поиск, анализ документа, валидация, конец
- **Шаблоны рабочих процессов** — Встроенные пресеты: ревью кода, исправление багов, документация, тестирование, рефакторинг, исследование, производительность, безопасность, разработка функциональности
- **Выполнение DAG** — Топологическая сортировка по алгоритму Кана с обнаружением циклов
- **Параллельное планирование** — Конвейерное выполнение, быстрые шаги не ждут медленные
- **Стратегия повторных попыток** — Экспоненциальный откат, настраиваемое максимальное количество попыток на шаг
- **Частичное завершение** — Неудачные шаги не блокируют независимые последующие шаги
- **Управление версиями** — Контроль версий шаблонов рабочих процессов с откатом
- **История выполнения** — Подробная запись с отслеживанием состояния и отладкой
- **ИИ-ассистирование** — Проектирование рабочих процессов с помощью ИИ, рекомендация узлов и оптимизация промптов агентов
- **Семантическая проверка** — Семантическая валидация рабочих процессов, обнаружение потенциальных проблем
- **Импорт n8n** — Поддержка импорта рабочих процессов из каталога n8n
- **Панель отладки** — Отладка в реальном времени и визуализация состояния во время выполнения рабочего процесса

### 📚 Знания и память

- **База знаний (RAG)** — Поддержка нескольких баз знаний, загрузка документов, автоматический парсинг, чанкинг и векторная индексация
- **Гибридный поиск** — Комбинация векторного поиска по сходству и полнотекстового ранжирования BM25
- **Self-RAG** — Генерация с автоматическим извлечением, интеллектуальное определение необходимости извлечения и релевантности результатов
- **Переранжирование** — Переранжирование кросс-энкодером для повышения точности извлечения
- **Трёхуровневый конвейер вызова** — Многоуровневый механизм вызова с AST-индексом + векторный поиск + FTS5
- **Граф знаний** — Визуализация связей сущность-знание (сущности, атрибуты, отношения, потоки, интерфейсы)
- **Система Wiki** — Компилятор и валидатор LLM Wiki с визуализацией графа знаний и инкрементной синхронизацией
- **Wiki-заметки** — Система заметок с двунаправленными ссылками, графовым представлением и автоматической синхронизацией ссылок
- **Система памяти** — Мультипространственная память с ручным вводом или автоматической ИИ-экстракцией
- **Замкнутая память** — Интеграция провайдеров постоянной памяти Honcho и Mem0
- **Полнотекстовый поиск FTS5** — Быстрый поиск по разговорам, файлам и воспоминаниям
- **Поиск по сессиям** — Расширенный поиск по всем сессиям разговоров
- **Управление контекстом** — Гибкое прикрепление файлов, результатов поиска, отрывков знаний, воспоминаний, выводов инструментов
- **Парсер документов** — Автоматический парсинг и извлечение содержимого из документов разных форматов
- **Инкрементная индексация** — Инкрементное обновление индекса при изменении файлов

- **Логи запросов** — Полная запись всех API-запросов и ответов
- **Шаблоны конфигурации** — Предустановленные шаблоны для Claude, Codex, OpenCode, Gemini

### 🛡️ Защита от инъекции промптов (Prompt-Guard)

- **Четырёхуровневая система защиты** — L1 обнаружение паттернов (перехват высокого риска + маркировка среднего риска) → L2 экранирование разделителей → L3 XML-обёртка → L4 теги доверия
- **Оркестратор Pipeline** — Многоуровневый конвейер обнаружения, поддержка настраиваемых порогов риска
- **Обнаружение Token Smuggling** — Специализированное обнаружение против обфускации кодирования и атак контрабанды токенов
- **Строгий режим** — Тестирование в строгом режиме + именование причин среднего риска + документация пользовательских режимов
- **Полная интеграция конвейера** — Интегрировано в session / prompt / git / RAG

#### Шаги сборки

```bash
# Клонировать репозиторий
git clone https://github.com/polite0803/AxAgent.git
cd AxAgent

# Установить зависимости
npm install

# Режим разработки
npm run tauri dev

# Собрать только фронтенд
npm run build

# Собрать десктоп-приложение
npm run tauri build
```

Артефакты сборки находятся в `src-tauri/target/release/`.

### Тестирование

```bash
# Модульные тесты
npm run test          # Vitest watch
npm run test:run      # Vitest однократный запуск

# E2E-тесты
npm run test:e2e      # Playwright
npm run test:e2e:ui   # Playwright режим UI

# Тестирование Rust-бэкенда
cd src-tauri && cargo nextest run   # cargo-nextest (в 2-3x быстрее)
cd src-tauri && cargo test          # Стандартные тесты

# Проверка типов
npm run typecheck     # TypeScript
cd src-tauri && cargo clippy -- -D warnings  # Rust

# Форматирование кода
npm run format        # dprint
cd src-tauri && cargo fmt

# CI-проверка
npm run ci:check
```

## Часто задаваемые вопросы

### macOS: «Приложение повреждено» или «Невозможно проверить разработчика»

Поскольку приложение не подписано Apple:

**1. Разрешить приложения из «Любого источника»**

```bash
sudo spctl --master-disable
```

Затем перейдите в **Системные настройки → Конфиденциальность и безопасность → Безопасность** и выберите **Любой источник**.

**2. Удалить атрибут карантина**

```bash
sudo xattr -dr com.apple.quarantine /Applications/AxAgent.app
```

**3. Дополнительный шаг для macOS Ventura+**
Перейдите в **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть**.
